# Web landing

Generate a self-contained HTML landing page.

## Guidelines

- Semantic HTML5 landmarks (`header`, `main`, `section`, `footer`)
- Accessible contrast and focus states
- Mobile-first CSS; avoid heavy frameworks unless asked
- Keep copy concise; prefer real section structure over lorem-only stubs

## Output

Write `index.html` (and optional `styles.css`) into the active Design Project.
