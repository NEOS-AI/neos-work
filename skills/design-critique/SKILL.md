# Design critique

Inspect the current design file (HTML/CSS) and give actionable feedback.

## Axes

- Visual hierarchy and typography scale
- Spacing rhythm and alignment
- Color contrast (WCAG AA where possible)
- Responsive breakpoints
- Interaction affordances

Prefer selection-scoped patches over full-file rewrites.
