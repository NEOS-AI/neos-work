# Migrating to NEOS Work v0.20.x

v0.20 finishes desktop client modularization:

| Track | Change |
|---|---|
| **C** | `EngineCatalogClient` — blocks, templates, memory |
| **D** | Design Project client split — Core → Collab → Files → ProjectClient |

No product API breaks from 0.19.x for callers of `engine.js`.

## Who is affected

| Surface | Impact |
|---|---|
| Desktop developers | Deeper hierarchy; **import path unchanged** |
| Operators | **No** env/server change |
| Workflows / SQLite | **No** data conversion |

---

## Hierarchy

### Product client

```text
EngineTransport → ProjectClient → Workflow → Settings → Media
  → Sessions → Plugins → Ops → Catalog → EngineClient
```

### Project sub-chain

```text
Transport → ProjectCore → ProjectCollab → ProjectFiles → EngineProjectClient
```

```ts
import {
  EngineClient,
  MemoryItem,
  EngineProjectCoreClient, // optional deep import
} from '../lib/engine.js';
```

## Upgrade checklist

1. From **0.19.x**: pull **≥ 0.20.0**; no data migration.  
2. Rebuild desktop.  
3. `pnpm inventory:check` (requires `v20Features`).
