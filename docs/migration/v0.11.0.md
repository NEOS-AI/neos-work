| Surface | Impact |

## Run → session bind (0.11.0)

```http
POST /api/runs
Content-Type: application/json
x-neos-session-id: <collab presence session>

{ "projectId": "…", "prompt": "…", "sessionId": "…" }
```

Response includes `collabSessionId`. Agent PUTs may pass `runId` / `x-neos-run-id`
to inherit that session under `NEOS_SHARED_EDIT=1` + `NEOS_SHARED_EDIT_AGENTS=1`.

---

## Tool files (0.11.2)

```http
POST /api/live-artifacts/tool-tokens
{ "projectId": "…", "runId": "…", "capabilities": ["files"] }

POST /api/tools/files/write
Authorization: Bearer ntt_…
{ "path": "index.html", "content": "…" }
```

Same **423** + `data.holder` as agent REST PUTs when locks hard-enforce agents.

CLI/MCP: when `NEOS_RUN_ID` or `NEOS_COLLAB_SESSION_ID` is set, file writes use
`source=agent` and attach session/run.

## Environment (unchanged from v0.10)

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_SHARED_EDIT` | off | Hard-enforce locks for **user** mutations |
| `NEOS_SHARED_EDIT_AGENTS` | off | Also hard-enforce `source=agent` (and tool files writes) |
| `NEOS_COLLAB_LOCKS` | `auto` | Multi-replica lock registry |
| `NEOS_COLLAB_BUS` / presence | as v0.8+ | Unchanged |

---

## Upgrade checklist

1. From **0.10.x**: no harness HTTP left — still use `/api/workers`.  
2. Optional: enable shared-edit + agents flags; pass collab session on run create.  
3. For agent tools: issue tokens with `files` capability; prefer bind runId.  
4. Update bookmarks to `/workers` if desired (`/harnesses` still works).  
5. Run `pnpm inventory:check` (requires `v11Features`).

No automatic SQLite / workflow migration required from 0.10.x.
