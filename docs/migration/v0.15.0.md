Operator map for “what does green mean?”:

| Tier | Command | When | Proves |
|---|---|---|---|
| **T0** Static | `pnpm e2e:smoke`, `pnpm inventory:check` | PR | Catalogs / docs / structural smoke |

| **T2** Process | `pnpm e2e:journey` | PR | Real `dist` server HTTP golden path (v0.14) |
| **T3** UI browser | **`pnpm e2e:browser`** | **PR (new in 0.15)** | Web Connect → Design Editor → Save → Preview |

## Browser E2E (`pnpm e2e:browser`)

Boots the **built** engine (`apps/server/dist/index.js`) and **Vite** web
(`@neos-work/web`) via Playwright `webServer`, then runs the Design Project
golden path in Chromium.

**Requires Node.js 22+** (same engines gate as journey). Fail-fast with a clear
message if major &lt; 22 or server dist is missing.

**One-time / CI browser install:**

```bash
pnpm exec playwright install chromium
# CI also uses --with-deps for system libraries
```

| # | Step | Expected |
|---|---|---|
| 1 | Connect URL + token | lands on `/projects` |
| 2 | Create project | navigates to `/projects/:id` |
| 3 | Seed `index.html` (API) + reload | file in tree; Design Editor open |
| 4 | Code mode edit + Save | dirty clears; no error alert |
| 5 | Preview mode | iframe `#hero` shows marker text |

Source: `e2e/browser/run.mjs`, `e2e/browser/playwright.config.ts`,
`e2e/browser/specs/design-project.spec.ts`.  
CI: `.github/workflows/ci.yml` builds server, installs Chromium, then runs browser e2e.

```bash
pnpm --filter @neos-work/server... build
pnpm exec playwright install chromium
pnpm e2e:browser
```

Optional env (defaults are fine for local/CI):

| Variable | Role |
|---|---|
| `NEOS_BROWSER_SERVER_PORT` | Engine port (default `14110`) |
| `NEOS_BROWSER_WEB_PORT` | Vite port (default `5174`) |
| `NEOS_AUTH_TOKEN` / `NEOS_BROWSER_TOKEN` | Bearer secret (config generates ephemeral if unset) |
| `NEOS_DATA_DIR` | Durable root (config uses ephemeral tmp if unset) |
| `NEOS_BROWSER_REUSE=1` | Reuse existing webServer when not in CI |

## Environment

Unchanged product flags from v0.10–v0.14 for shared-edit / multi-replica.
Browser E2E does **not** require `NEOS_SHARED_EDIT` (user-only Connect path).

| Variable | Role |
|---|---|
| `NEOS_SHARED_EDIT` | User lock hard-enforce (journey / multi-replica) |
| `NEOS_SHARED_EDIT_AGENTS` | Also enforce `source=agent` (live L7) |
| `NEOS_COLLAB_BUS` / `NEOS_COLLAB_*` | Multi-replica collab (nightly live) |
| `NEOS_DATA_DIR` | Durable root; journey/browser/live use ephemeral dirs |
| `NEOS_AUTH_TOKEN` | Bearer secret |

## Upgrade checklist

1. From **0.14.x**: pull **≥ 0.15.0**; **no data migration scripts**.  
2. Local/CI: Node **22+**; ensure PR CI runs `e2e:contract`, `e2e:journey`, **and** `e2e:browser`.  
3. After server changes: `pnpm --filter @neos-work/server... build` before journey/browser.  
4. Install Playwright Chromium once per machine / CI image: `pnpm exec playwright install chromium`.  
5. Run `pnpm inventory:check` (requires `v15Features`).
