# Migrating to NEOS Work v0.10.x

v0.10 is primarily an **ops / collab / API hygiene** train on top of v0.9 Design
Editor completion. Local SQLite and schemaVersion 2 workflows remain compatible.

Plan: [`docs/plans/PLAN_FOR_V0_10_0.md`](../plans/PLAN_FOR_V0_10_0.md)  
Parent: [`docs/migration/v0.9.0.md`](./v0.9.0.md)

API surface: [`docs/reference/api-surface-notes.md`](../reference/api-surface-notes.md)

> Closeout release: **0.10.3** (docs + inventory `v10Features` gates).

---

## Who is affected

| Surface | Impact |
|---|---|
| Multi-replica operators | Optional shared **lock** registry (`NEOS_COLLAB_LOCKS`) + agent lock enforce flags |
| Scripts / external clients using `/api/harness*` | **Breaking in 0.10.2** — use `/api/workers` |
| Desktop / Web product UI | No harness HTTP dependency (workers only) |
| Workflows / packs / Design Projects | **No data conversion** |
| Auth / Docker / Helm | Prefer tags **≥ 0.10.3**; data under `NEOS_DATA_DIR` compatible |

## Environment flags (v0.10)

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_SHARED_EDIT` | off | Hard-enforce file locks for **user** mutations |
| `NEOS_SHARED_EDIT_AGENTS` | off | Also hard-enforce `source=agent` PUTs when base is on |
| `NEOS_COLLAB_LOCKS` | `auto` | `auto` \| `memory` \| `redis` \| `off` — lock registry (mirrors presence) |
| `NEOS_COLLAB_BUS` | `memory` | Unchanged from v0.8/v0.9 |
| `NEOS_COLLAB_PRESENCE` | `auto` | Unchanged |
| `NEOS_COLLAB_REDIS_URL` / `REDIS_URL` | unset | Shared Redis for bus + registries |

```bash
# Multi-replica collab with shared locks + user hard-enforce
NEOS_COLLAB_BUS=redis \
NEOS_COLLAB_REDIS_URL=redis://127.0.0.1:6379 \
NEOS_COLLAB_LOCKS=auto \
NEOS_SHARED_EDIT=1 \
NEOS_AUTH_TOKEN=dev-shared-token \
  pnpm --filter @neos-work/server dev
```

## Breaking: `/api/harness` and `/api/harnesses` (0.10.2)

These paths return **HTTP 410 Gone** with `Link: </api/workers>; rel="successor-version"`.

| Old | New |
|---|---|
| `GET/POST /api/harness` | `GET/POST /api/workers` |
| `GET/PUT/DELETE /api/harness/:id` | `GET/PUT/DELETE /api/workers/:id` |
| Same under `/api/harnesses` | Same under `/api/workers` |

**Checklist**

1. Update any scripts, curl samples, or external clients still calling harness URLs.  
2. Prefer `listWorkers` / `createWorker` / … client methods (desktop already does).  
3. Desktop page URL `/harnesses` is **unchanged** (UI only); it talks to `/api/workers`.  
4. In-process workflow-engine `listHarnesses` helpers remain (not HTTP).

See [`docs/implementation/v0.10/v0.10.2.md`](../implementation/v0.10/v0.10.2.md).

## Multi-replica locks (0.10.1+)

With `NEOS_COLLAB_BUS=redis` and `NEOS_COLLAB_LOCKS=auto`, lock acquire dual-writes Redis
keys so list + hard-enforce agree across replicas.

| Behavior | Detail |
|---|---|
| Dual-write | Acquire/release **await** registry put/del |
| Hydrate | **Fill-missing only**; does not overwrite local lock map entries |
| Tombstones | Local release suppresses re-hydrate of that path for a short window |
| TTL refresh | On presence **heartbeat** interval (not every SSE tick) |
| Status | `GET /api/collab/status` → `data.locks` |

Redis keys: `neos:collab:lock:{projectId}:{path}`, `neos:collab:locks:{projectId}` (TTL ~270s).  
See ops: [`docs/ops/multi-replica-collab.md`](../ops/multi-replica-collab.md).

## Agent hard-enforce (0.10.0)

| Flags | User PUT on locked path | Agent PUT on locked path |
|---|---|---|
| both off | allowed (advisory) | allowed |
| SHARED only | 423 unless holder | **allowed** (bypass) |
| both on | 423 unless holder | **423** unless holder session |

Agent as holder: `sessionId` body and/or `x-neos-session-id`.
