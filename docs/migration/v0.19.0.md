# Migrating to NEOS Work v0.19.x

v0.19 ships two parallel tracks:

| Track | Change |
|---|---|
| **A** | Desktop `EngineOpsClient` — design systems, artifacts, routines, deploy |
| **B** | Shared **run event** buffer — multi-replica GET/SSE for run events |

No product API breaks from 0.18.x for desktop callers of `engine.js`.

Plan: [`docs/plans/PLAN_FOR_V0_19_0.md`](../plans/PLAN_FOR_V0_19_0.md)  
Parent: [`docs/migration/v0.18.0.md`](./v0.18.0.md)  
Release: [`docs/releases/v0.19.0.md`](../releases/v0.19.0.md)

> Monorepo **0.19.0** is the v0.19 line (see `docs/implementation/v0.19/`).

---

## Who is affected

| Surface | Impact |
|---|---|
| Desktop developers | Ops methods on `EngineOpsClient`; **import path unchanged** |
| Multi-replica operators | Run event GET/SSE work across pods when `NEOS_RUN_REGISTRY` not `off` |
| Single-process | **No behaviour change** (local path first) |
| Workflows / SQLite / projects | **No data conversion** |

## Environment (Track B)

No new env vars. Reuses:

| Variable | Role |
|---|---|
| `NEOS_RUN_REGISTRY` | `auto\|memory\|redis\|off` — summaries **and** event buffer |
| `NEOS_COLLAB_BUS` / Redis URL | Same as v0.16 for redis mode |

| Redis key | Role |
|---|---|
| `neos:run:summary:{id}` | Summary (existing) |
| `neos:run:events:{id}` | Event LIST (cap 500, TTL ~1h) |
| `neos:run:eventbus` | Optional pub/sub |
| `neos:run:commands` | Cancel (existing) |

When registry is `off`, remote event routes still **404** (local-only).

---

## Upgrade checklist

1. From **0.18.x**: pull **≥ 0.19.0**; no data migration.  
2. Desktop: rebuild; keep `engine.js` imports.  
3. Multi-replica: ensure `NEOS_RUN_REGISTRY` not `off` if you need cross-pod run SSE.  
4. `pnpm inventory:check` (requires `v19Features`).
