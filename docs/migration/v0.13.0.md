# Migrating to NEOS Work v0.13.x

v0.13 locks **shared-edit wire** (0.10–0.11) into the PR **FE/BE contract** suite.
No runtime product surface changes beyond tests and docs.

Plan: [`docs/plans/PLAN_FOR_V0_13_0.md`](../plans/PLAN_FOR_V0_13_0.md)  
Parent: [`docs/migration/v0.12.0.md`](./v0.12.0.md)  
Release: [`docs/releases/v0.13.3.md`](../releases/v0.13.3.md)

> Treat monorepo **0.13.0–0.13.x** as the v0.13 line (see `docs/implementation/v0.13/`).  
> Closeout release: **0.13.3** (docs + inventory `v13Features` gates).

## Who is affected

| Surface | Impact |

## Contract suite (`pnpm e2e:contract`)

Runs in GitHub Actions on every PR (`.github/workflows/ci.yml`).

| # | Case |
|---|---|
| 1 | Write response `hash` (not revision `contentHash`) |
| 2 | Lock acquire **409** + `data.holder` |
| 3 | Peers / locks snapshots (flags off by default) |
| 4 | Multi-selection snapshot |
| 5 | Dry-run create + terminal cancel **409** |
| 6 | Agent hard-enforce **423** holder shape |
| 7 | Run bind + agent PUT via `runId` |
| 8 | `POST /api/tools/files/write` hash + **423** when locked |
| 9 | Locks `hardEnforce` / `agentsHardEnforce` when env on |
| 10 | Dry-run summary `collabSessionId` (body/header/unbound) |

Source: `apps/server/src/routes/contract-fe-be.test.ts`.

## Upgrade checklist

1. From **0.12.x**: pull **≥ 0.13.3**; no migration scripts.  
2. Ensure CI runs `pnpm e2e:contract` (already default).  
3. Run `pnpm inventory:check` (requires `v13Features`).
