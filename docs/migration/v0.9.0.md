# Migrating to NEOS Work v0.9.x

v0.9 is an **additive** train on top of v0.8 collab/contract hardening.
**No automatic data conversion** is required. Workflows (schemaVersion 2),
Design Projects, skills/plugins, and local SQLite remain compatible.

Plan: [`docs/plans/PLAN_FOR_V0_9_0.md`](../plans/PLAN_FOR_V0_9_0.md)  
Parent: [`docs/migration/v0.8.0.md`](./v0.8.0.md)  
Security: [`docs/security/v0.5.md`](../security/v0.5.md) (still applies)  
Dual-surface: [`docs/reference/dual-surface.md`](../reference/dual-surface.md)  
ADR shared-edit: [`docs/adr/0001-shared-edit-strategy.md`](../adr/0001-shared-edit-strategy.md)

> Treat monorepo **0.9.0–0.9.x** as the v0.9 line (see `docs/implementation/v0.9/`).  
> Closeout release: **0.9.4** (docs + inventory `v09Features` gates).

## Who is affected

| Surface | Impact |
|---|---|
| Workflows / domain packs | **No change** |
| Design Editor | Layers **sibling reorder**; canvas **default-on**; align / distribute / z-order |
| Web client | Preview **comments** + project **zip** I/E; dual-surface badge |
| Desktop | Same editor package + Settings canvas toggle; marketplace remains desktop |
| Collab multi-node | Unchanged from v0.8 (bus + presence registry) |
| Auth / Docker / Helm | Prefer tags **≥ 0.9.4**; data under `NEOS_DATA_DIR` compatible |
| CRDT / multi-caret | **Still out of scope** (Q19 / Q22 / Q27) |

## Environment / preference flags

| Variable / key | Default | Meaning |
|---|---|---|
| `VITE_NEOS_CANVAS_OVERLAY` / `NEOS_CANVAS_OVERLAY` | unset | **`0`/`false` forces off**; `1`/`true` forces on. When unset, canvas is **on** (0.9.1+) unless user pref says otherwise |
| `localStorage['neos.canvasOverlay']` | unset | User pref `1` / `0` (desktop + web Settings; DesignEditor toggle) |
| `NEOS_COLLAB_BUS` | `memory` | Unchanged from v0.8 |
| `NEOS_COLLAB_PRESENCE` | `auto` | Unchanged from v0.8 |
| `NEOS_SHARED_EDIT` | off | Hard file-lock enforce; agent writes still bypass ([ADR 0001](../adr/0001-shared-edit-strategy.md)) |
| `NEOS_AUTH_TOKEN` | (process random) | Unchanged |

```bash
# Force canvas off (ops / CI)
VITE_NEOS_CANVAS_OVERLAY=0 pnpm --filter @neos-work/web dev

# Default: canvas on without env
pnpm --filter @neos-work/web dev
```

**Breaking UX note:** Operators who relied on canvas being **off** unless
`VITE_NEOS_CANVAS_OVERLAY=1` must set `=0` or turn the Settings toggle off after
upgrade.

### Manual QA checklist

1. **Layers reorder** — HTML project: drag sibling above another; save; reload order  
2. **Canvas default** — fresh browser/profile: Canvas badge on without env; Settings off sticks  
3. **Align / z-order** — multi-select with bboxes; z-order changes Code DOM order  
4. **Web comments** — select element → add comment → run AI (server injects)  
5. **Web zip** — export project; import zip → navigates to new project
