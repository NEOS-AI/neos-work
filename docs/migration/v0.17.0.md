# Migrating to NEOS Work v0.17.x

v0.17 continues desktop `EngineClient` modularization: **skills**, **media**, and
**live artifacts** move to `EngineMediaClient`. No product API breaks from 0.16.x.

Plan: [`docs/plans/PLAN_FOR_V0_17_0.md`](../plans/PLAN_FOR_V0_17_0.md)  
Parent: [`docs/migration/v0.16.0.md`](./v0.16.0.md)  
Release: [`docs/releases/v0.17.0.md`](../releases/v0.17.0.md)

> Monorepo **0.17.0** is the v0.17 line (see `docs/implementation/v0.17/`).

---

## Who is affected

| Surface | Impact |
|---|---|
| Desktop developers | Skills / media / live artifacts live on `EngineMediaClient`; **import path unchanged** (`engine.js`) |
| Operators / multi-replica | **No change** from 0.16.x run registry defaults |
| Workflows / SQLite / projects | **No data conversion** from 0.16.x |
| Auth / Docker / Helm | Prefer tags **≥ 0.17.0**; data under `NEOS_DATA_DIR` compatible |

| Version | Feature |
|---|---|
| **0.17.0** | **M0** — Desktop `EngineMediaClient` extract (skills + media + live artifacts) |

## Hierarchy (developers)

```text
EngineTransport
  → EngineProjectClient
    → EngineWorkflowClient
      → EngineSettingsClient
        → EngineMediaClient   // NEW (v0.17)
          → EngineClient
```

| Class | File | Role |
|---|---|---|
| `EngineTransport` | `engine-transport.ts` | baseUrl, auth, headers |
| `EngineProjectClient` | `engine-project.ts` | Design Project, collab, files, runs |
| `EngineWorkflowClient` | `engine-workflow.ts` | workflows, deploys, webhooks |
| `EngineSettingsClient` | `engine-settings.ts` | settings, connection-test, MCP |
| `EngineMediaClient` | `engine-media.ts` | skills, media, live artifacts |
| `EngineClient` | `engine.ts` | remaining domains + re-exports |

```ts
// Still correct — public surface re-exports types and EngineClient
import { EngineClient, SkillData, SkillExampleCard } from '../lib/engine.js';
```

No call-site renames required for app code that already imports from `engine.js`.

---

## Environment

No new environment variables in 0.17.0. Existing `NEOS_RUN_REGISTRY` and collab
settings from v0.16 remain as documented in [migration v0.16](./v0.16.0.md).

---

## Upgrade checklist

1. From **0.16.x**: pull **≥ 0.17.0**; **no data migration scripts**.  
2. Desktop: rebuild; prefer `import … from '…/engine.js'` only (skills/media moved internally).  
3. Run `pnpm inventory:check` (requires `v17Features`).
