# Migrating to NEOS Work v0.7.x

v0.7 is an **additive** train on top of v0.6 collab foundations and the Design
Editor canvas overlay. **No automatic data conversion** is required. Workflows
(schemaVersion 2), Design Projects, skills/plugins, and local SQLite remain
compatible.

Plan: [`docs/plans/PLAN_FOR_V0_7_0.md`](../plans/PLAN_FOR_V0_7_0.md)  
Parent: [`docs/migration/v0.6.0.md`](./v0.6.0.md)  
Security: [`docs/security/v0.5.md`](../security/v0.5.md) (still applies)  
ADR shared-edit: [`docs/adr/0001-shared-edit-strategy.md`](../adr/0001-shared-edit-strategy.md)

> Treat monorepo **0.7.0–0.7.x** as the v0.7 line (see `docs/implementation/v0.7/`).  
> Closeout release: **0.7.4** (docs + inventory gates).

---

## Who is affected

| Surface | Impact |
|---|---|
| Workflows / domain packs | **No change** |
| Design Projects / Editor | Additive: canvas resize, multi-select, collab selection awareness |
| Collab multi-node | **Optional** Redis bus (`NEOS_COLLAB_BUS=redis`); default remains in-process memory |
| Auth / Docker / Helm | Same single-replica guidance; tags **≥ 0.7.4** recommended |
| CRDT / multi-caret | **Still out of scope** (Q19) |

| Version | Feature |

## Environment flags

| Variable | Default | Meaning |
|---|---|---|
| `VITE_NEOS_CANVAS_OVERLAY` / `NEOS_CANVAS_OVERLAY` | off | Canvas overlay: move + resize (+ multi when selecting) |
| `NEOS_COLLAB_BUS` | `memory` | `memory` \| `redis` |
| `NEOS_COLLAB_REDIS_URL` / `REDIS_URL` | unset | Required for real Redis bus; else redis-stub |
| `NEOS_SHARED_EDIT` | off | Unchanged from v0.6.3 — hard file-lock enforce |
| `NEOS_AUTH_TOKEN` | (process random) | Unchanged — not logged in full when set via env |

```bash
# Canvas overlay (web/desktop Vite)
VITE_NEOS_CANVAS_OVERLAY=1 pnpm --filter @neos-work/web dev

# Optional multi-node collab bus prep
# pnpm add redis -F @neos-work/server
NEOS_COLLAB_BUS=redis NEOS_COLLAB_REDIS_URL=redis://127.0.0.1:6379 \
  pnpm --filter @neos-work/server dev
```

## API additions (high level)

| Area | Paths / events |
|---|---|
| Collab bus status | `GET /api/collab/status` → `{ bus, nodeId, ready, detail }` |
| Selection awareness | `POST /api/projects/:id/collab/selection` |
| | `GET /api/projects/:id/collab/selections` |
| | SSE: `selection.changed`; `presence.sync.selections[]` |
| Existing collab | `…/collab/stream`, `…/peers`, `…/heartbeat`, `…/locks` (v0.6) |

### `PeerSelection` (awareness only — not exclusive)

```ts
{
  sessionId, displayName, colorHint,
  path: string | null,
  selector: string | null,
  layerId?: string | null,
  updatedAt: string
}
```

Paths use the same sanitizer as file locks (no `..`, no control chars).

## Design Editor UX deltas

| Feature | How |
|---|---|
| Resize | Opt-in canvas overlay → drag **SE** corner on primary frame |
| Multi-select | **Shift+click** (or ⌘) in Inspect/Layers; multi dashed bboxes |
| Multi-move | Drag primary frame → same `left`/`top` delta on all selected |
| Resize multi | **Primary only** (no group scale) |
| Peer selection | Avatars show path · selector when peers publish awareness |

Collab selection multi-set is **session-local** (not broadcast as multi); M2 still sends the **primary** path/selector for peer indicators.

## Upgrade steps

1. Deploy monorepo **≥ 0.7.4** (Docker image tag / Helm `appVersion`).  
2. Keep a stable `NEOS_AUTH_TOKEN` in secret/env.  
3. Optional: enable canvas with `VITE_NEOS_CANVAS_OVERLAY=1`.  
4. Optional: multi-node prep with `NEOS_COLLAB_BUS=redis` + Redis URL  
   (install optional `redis` peer dep on `@neos-work/server`).  
5. Prefer **one engine replica** unless multi-replica is configured (see  
   [`v0.8.0.md`](./v0.8.0.md) for shared presence + Redis registry).  
6. Run CI gates:

```bash
pnpm inventory:check
pnpm e2e:smoke
# optional acceptance
pnpm e2e:c5
```

---

## Rollback

Point image/tag back to **0.6.5** or earlier **0.7.x**. User data under
`NEOS_DATA_DIR` / `~/.neos-work` is compatible. New env flags can remain unset
(defaults keep prior behavior).
