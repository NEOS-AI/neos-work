# Migrating to NEOS Work v0.21.x

v0.21 deepens multi-replica run reliability:

| Track | Change |
|---|---|
| **1** | Durable run event JSONL (`NEOS_RUN_EVENT_LOG`) |
| **2** | Multi-replica e2e L9 (cross-pod events) + L10 (disk log) |

No desktop API breaks. No SQLite schema migration.

Plan: [`docs/plans/PLAN_FOR_V0_21_0.md`](../plans/PLAN_FOR_V0_21_0.md)  
Parent: [`docs/migration/v0.20.0.md`](./v0.20.0.md)  
Release: [`docs/releases/v0.21.0.md`](../releases/v0.21.0.md)

---

## Who is affected

| Surface | Impact |
|---|---|
| Operators (multi-replica) | Disk usage under `NEOS_DATA_DIR/runs/`; share volume for durable recovery |
| Single-process local | JSONL under data dir by default (`auto`) — set `NEOS_RUN_EVENT_LOG=off` to disable |
| Desktop / web clients | Unchanged wire format for events |

---

## Environment

| Variable | Default | Notes |
|---|---|---|
| `NEOS_RUN_EVENT_LOG` | `auto` | `on` / `off` / `auto` |
| `NEOS_RUN_REGISTRY` | `auto` | Unchanged — buffer + summary |
| `NEOS_DATA_DIR` | (see server) | Root for `runs/{id}/events.jsonl` |

---

## Upgrade checklist

1. From **0.20.x**: pull **≥ 0.21.0**.  
2. Multi-replica: ensure shared `NEOS_DATA_DIR` if you want JSONL recovery across pods.  
3. Optional: `NEOS_RUN_EVENT_LOG=off` if disk logs undesired.  
4. `pnpm inventory:check` (`v21Features`).  
5. Optional live: `pnpm e2e:multi-replica:live`.
