# Migrating to NEOS Work v0.14.x

v0.14 proves the **running engine** (not only in-process Hono) can complete the
Design Project golden path on every PR, and deepens **nightly multi-replica**
lock hard-enforce (user + agent). No product API breaks from 0.13.x.

Plan: [`docs/plans/PLAN_FOR_V0_14_0.md`](../plans/PLAN_FOR_V0_14_0.md)  
Parent: [`docs/migration/v0.13.0.md`](./v0.13.0.md)  
Release: [`docs/releases/v0.14.1.md`](../releases/v0.14.1.md)

> Treat monorepo **0.14.0–0.14.x** as the v0.14 line (see `docs/implementation/v0.14/`).  
> Closeout release: **0.14.1** (M3 multi-replica L7 + docs + inventory `v14Features`).

Operator map for “what does green mean?”:

| Tier | Command | When | Proves |
|---|---|---|---|
| **T0** Static | `pnpm e2e:smoke`, `pnpm inventory:check` | PR | Catalogs / docs / structural smoke |
| **T1** Wire | `pnpm e2e:contract` | PR | In-process shared-edit shapes (v0.13) |
| **T2** Process | **`pnpm e2e:journey`** | **PR (new in 0.14)** | Real `dist` server HTTP golden path |
| **T3** UI browser | *(deferred M2)* | — | Web Connect → Design Editor |
| **T4** Topology | `pnpm e2e:multi-replica:live` | Nightly | Dual engine + Redis + locks L1–L8 |

## Process journey (`pnpm e2e:journey`)

Boots `apps/server/dist/index.js` with ephemeral `NEOS_DATA_DIR` + `NEOS_AUTH_TOKEN`,
then asserts the Design Project HTTP path clients depend on.

**Requires Node.js 22+** (native modules / `engines.node`). Fail-fast with a clear
message if major &lt; 22 or server dist is missing.

| # | Step | Expected |
|---|---|---|
| 1 | Node engines | Fail fast if Node major &lt; 22 |
| 2 | `GET /api/health` | **200** with Bearer |
| 3 | `POST /api/projects` | **201** + `data.id` |
| 4 | `PUT …/files/index.html` | **200** + body `hash` (not only `contentHash`) |
| 5 | Collab SSE `ready` | `sessionId` for two peers |
| 6 | Lock acquire A + B same path | **409** + holder for second |
| 7 | `NEOS_SHARED_EDIT=1` foreign user PUT | **423** + holder |
| 8 | Holder user PUT | **200** |
| 9 | Dry-run `POST /api/runs` + cancel | create ok; second cancel **409** if terminal |

Source: `e2e/journey/run.mjs`.  
CI: `.github/workflows/ci.yml` builds `@neos-work/server...` then runs journey.

```bash
pnpm --filter @neos-work/server... build
pnpm e2e:journey
```

## Multi-replica live (L5–L8)

Nightly / opt-in live probes (`pnpm e2e:multi-replica:live` or
`NEOS_MULTI_REPLICA_E2E=1`). Requires Redis + two engine processes + shared data dir.

| # | Case | Status |
|---|---|---|
| L1 | Dual health + redis bus | existing |
| L2 | Shared data project visible on B | existing |
| L3 | Cross-replica peers | existing |
| L4 | Selection fan-out A→B | existing |
| L5 | Lock acquire A → list on B | existing (0.10.1) |
| L6 | Foreign **user** PUT on B → **423** | existing |
| **L7** | Foreign **agent** PUT on B → **423** when agents flag on | **new 0.14.1** |
| L8 | Collab status `locks.kind` present | existing |

L7 enables `NEOS_SHARED_EDIT=1` + `NEOS_SHARED_EDIT_AGENTS=1` on both replicas and
asserts an agent PUT without holder session is blocked on replica B with holder from A.

Source: `e2e/multi-replica/run.mjs`. Ops: [`docs/ops/multi-replica-collab.md`](../ops/multi-replica-collab.md).

## Environment

Unchanged product flags from v0.10–v0.13 for shared-edit / multi-replica:

| Variable | Role |
|---|---|
| `NEOS_SHARED_EDIT` | User lock hard-enforce (journey sets `1` for case 7) |
| `NEOS_SHARED_EDIT_AGENTS` | Also enforce `source=agent` / tools files (live L7) |
| `NEOS_COLLAB_BUS` / `NEOS_COLLAB_*` | Multi-replica collab (nightly live) |
| `NEOS_DATA_DIR` | Durable root; journey/live use ephemeral dirs |
| `NEOS_AUTH_TOKEN` | Bearer secret (journey generates ephemeral token) |

Optional journey debug: `NEOS_JOURNEY_PORT`, `NEOS_JOURNEY_VERBOSE=1`.

## Upgrade checklist

1. From **0.13.x**: pull **≥ 0.14.1**; **no data migration scripts**.  
2. Local/CI: Node **22+**; ensure PR CI runs `pnpm e2e:contract` **and** `pnpm e2e:journey`.  
3. After server changes: `pnpm --filter @neos-work/server... build` before journey.  
4. Run `pnpm inventory:check` (requires `v14Features`).  
5. Multi-replica operators: no new deploy flags; agent 423 already product since 0.10 — L7 only deepens nightly proof.
