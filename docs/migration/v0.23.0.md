## Track K — secrets key

| Env | Meaning |
|---|---|
| `NEOS_MASTER_KEY` | Prefer this material for AES key (hex/base64/string→hash) |
| `NEOS_SECRETS_KEY_BACKEND` | `auto` \| `env` \| `file` \| `legacy` |

**`auto`:** env → existing file key under `{data}/.secrets/master.key` → legacy machine hash.  
**Does not** auto-create file key (preserves decrypt for existing SQLite secrets).

Startup log: `NEOS_SECRETS_KEY_SOURCE=env|file|legacy` (never logs key material).

Changing master key without re-encrypting secrets will break decrypt of existing API keys — rotate carefully.

## Track P — warehouse

| Env | Default |
|---|---|
| `NEOS_RUN_WAREHOUSE` | `off` |
| `NEOS_RUN_WAREHOUSE_URL` or `DATABASE_URL` | unset |
| `NEOS_RUN_WAREHOUSE_SCHEMA` | `public` |

When `postgres` + URL + `pg` package: dual-writes summaries/events; GET falls back after local/shared/JSONL.  
Missing URL → `postgres-stub` (no-op).
