## OS keyring

| Env | Notes |
|---|---|
| `NEOS_SECRETS_KEY_BACKEND=os` | Prefer/require OS keyring; auto-create key |
| `NEOS_SECRETS_KEY_BACKEND=auto` | env → OS (if key present) → file → legacy |

Service `neos-work` / account `master-key` (base64 of 32 bytes).  
Install optional `keytar` native module for Node daemon; desktop uses Tauri `keyring` crate.
