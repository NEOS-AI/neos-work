# Migrating to NEOS Work v0.18.x

v0.18 continues desktop `EngineClient` modularization: **sessions / chat / agent /
workspaces** move to `EngineSessionsClient`; **plugins / marketplace / workers /
domain packs** move to `EnginePluginsClient`. No product API breaks from 0.17.x.

Plan: [`docs/plans/PLAN_FOR_V0_18_0.md`](../plans/PLAN_FOR_V0_18_0.md)  
Parent: [`docs/migration/v0.17.0.md`](./v0.17.0.md)  
Release: [`docs/releases/v0.18.0.md`](../releases/v0.18.0.md)

> Monorepo **0.18.0** is the v0.18 line (see `docs/implementation/v0.18/`).

---

## Who is affected

| Surface | Impact |
|---|---|
| Desktop developers | Sessions / plugins live on new base classes; **import path unchanged** (`engine.js`) |
| Operators / multi-replica | **No change** from 0.17.x |
| Workflows / SQLite / projects | **No data conversion** from 0.17.x |
| Auth / Docker / Helm | Prefer tags **≥ 0.18.0**; data under `NEOS_DATA_DIR` compatible |

## Hierarchy (developers)

```text
EngineTransport
  → EngineProjectClient
    → EngineWorkflowClient
      → EngineSettingsClient
        → EngineMediaClient
          → EngineSessionsClient   // NEW (v0.18 M0)
            → EnginePluginsClient  // NEW (v0.18 M1)
              → EngineClient
```

| Class | File | Role |
|---|---|---|
| `EngineMediaClient` | `engine-media.ts` | skills, media, live artifacts |
| `EngineSessionsClient` | `engine-sessions.ts` | health, sessions, chat/agent, workspaces |
| `EnginePluginsClient` | `engine-plugins.ts` | plugins, marketplace, workers, packs |
| `EngineClient` | `engine.ts` | design systems, artifacts, routines, blocks, memory + re-exports |

```ts
// Still correct — public surface re-exports types and EngineClient
import {
  EngineClient,
  SessionData,
  AgentChunk,
  SkillData,
} from '../lib/engine.js';
```

No call-site renames required for app code that already imports from `engine.js`.

## Environment

No new environment variables in 0.18.0.

---

## Upgrade checklist

1. From **0.17.x**: pull **≥ 0.18.0**; **no data migration scripts**.  
2. Desktop: rebuild; prefer `import … from '…/engine.js'` only.  
3. Run `pnpm inventory:check` (requires `v18Features`).
