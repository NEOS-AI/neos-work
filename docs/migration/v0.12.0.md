# Migrating to NEOS Work v0.12.x

v0.12 is a **maintainability and ops-docs** train on top of v0.11 agent lock
identity. Local SQLite and schemaVersion 2 workflows remain compatible.

Plan: [`docs/plans/PLAN_FOR_V0_12_0.md`](../plans/PLAN_FOR_V0_12_0.md)  
Parent: [`docs/migration/v0.11.0.md`](./v0.11.0.md)  
Release: [`docs/releases/v0.12.3.md`](../releases/v0.12.3.md)  
Ops multi-replica: [`docs/ops/multi-replica-collab.md`](../ops/multi-replica-collab.md)  
Sticky SSE (design only): [`docs/ops/sticky-sse.md`](../ops/sticky-sse.md)

> Treat monorepo **0.12.0–0.12.x** as the v0.12 line (see `docs/implementation/v0.12/`).  
> Closeout release: **0.12.3** (docs + inventory `v12Features` gates).

---

## Who is affected

| Surface | Impact |
|---|---|
| Desktop developers | `EngineClient` split into modules; **import path unchanged** (`engine.js`) |
| Multi-replica operators | Clearer **file SSOT / `NEOS_DATA_DIR`** guidance; sticky SSE still not product |
| Workflows / packs / Design Projects | **No data conversion** |
| Auth / Docker / Helm | Prefer tags **≥ 0.12.3**; data under `NEOS_DATA_DIR` compatible |

## Desktop client layout (developers)

```text
EngineTransport       → engine-transport.ts
  EngineProjectClient → engine-project.ts   (Design Project, collab, runs)
    EngineWorkflowClient → engine-workflow.ts (workflows, webhook, deploy)
      EngineClient    → engine.ts           (sessions, MCP, media, workers, …)
```

```ts
// Still correct — public surface re-exports types and EngineClient
import { EngineClient, DesignProject, Workflow } from '../lib/engine.js';
```

No call-site renames required for app code that already imports from `engine.js`.

---

## Multi-replica / data dir (operators)

| Topic | Guidance |
|---|---|
| Collab events | Redis bus + presence/lock registries (unchanged from v0.10+) |
| File bytes | Disk under `NEOS_DATA_DIR` remains SSOT (not synced by Redis) |
| SQLite | **Multi-writer on one volume unsupported** |
| Sticky SSE | **Not implemented** — see design note |

Full detail: [File content SSOT](../ops/multi-replica-collab.md#file-content-ssot-neos_data_dir).

---

## Environment

No new required env flags in v0.12. Existing collab flags from v0.8–v0.11 still apply:

| Variable | Role |
|---|---|
| `NEOS_COLLAB_BUS` / `NEOS_COLLAB_*` | Multi-replica collab |
| `NEOS_SHARED_EDIT` / `NEOS_SHARED_EDIT_AGENTS` | Lock hard-enforce |
| `NEOS_DATA_DIR` | Durable root (projects, SQLite, media) |
| `NEOS_AUTH_TOKEN` | Shared secret across replicas |

---

## Upgrade checklist

1. From **0.11.x**: pull **≥ 0.12.3**; no workflow/SQLite migration.  
2. Desktop: rebuild packages if you import deep paths — prefer `engine.js` only.  
3. Multi-replica: re-read [ops multi-replica](../ops/multi-replica-collab.md) file SSOT section.  
4. Run `pnpm inventory:check` (requires `v12Features`).
