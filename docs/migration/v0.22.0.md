# Migrating to NEOS Work v0.22.x

v0.22 productionizes durable run logs:

| M | Change |
|---|---|
| **M0** | Retention/GC for `runs/*` |
| **M1** | Durable `summary.json` |
| **M2** | Nightly live multi-replica e2e |

No desktop API breaks. No SQLite migration.

## New / changed env

| Variable | Default | Notes |
|---|---|---|
| `NEOS_RUN_EVENT_LOG_MAX_AGE_HOURS` | `168` | Age prune |
| `NEOS_RUN_EVENT_LOG_MAX_RUNS` | `500` | Count prune |
| `NEOS_RUN_EVENT_LOG_MAX_FILE_BYTES` | `8388608` | Per-file trim |

Disk layout adds `summary.json` beside `events.jsonl`.

---

## Upgrade checklist

1. From **0.21.x**: pull **≥ 0.22.0**.  
2. Multi-replica: keep shared `NEOS_DATA_DIR`.  
3. Tune retention env if long-lived run logs are required.  
4. `pnpm inventory:check` (`v22Features`).  
5. Optional: enable nightly workflow on GitHub Actions (schedule already defined).
