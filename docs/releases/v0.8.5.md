## Highlights

### Design Editor canvas (C polish)

| Item | Notes |
|---|---|
| Uniform group scale | Hold **Shift** during multi-select SE resize → `sx = sy` |
| Canvas transform undo | Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z for move/resize (cap ~20); not full doc history |
| Ctrl/Cmd multi-select | Bridge + Layers: `shiftKey \|\| metaKey \|\| ctrlKey` additive select |
| Peer outline frames API | `peerFrames` / `peerCanvasFrames` for dashed peer bboxes (host supplies measured boxes) |
| JSX multi-select | Best-effort via Layers; group chrome remains HTML-bridge only |

Canvas overlay stays **opt-in**:

```bash
VITE_NEOS_CANVAS_OVERLAY=1 pnpm --filter @neos-work/web dev
# or NEOS_CANVAS_OVERLAY=1 for server-injected hosts
```

### Ops / docs

- Train summary and multi-replica recipe remain under [ops multi-replica collab](../ops/multi-replica-collab.md)
- GitHub Actions CI (Node **22**, typecheck, inventory, test, e2e smoke) under `.github/workflows/ci.yml`
- Engines: `node >= 22` — rebuild native modules (`better-sqlite3`) when switching Node major

Auth / data under `NEOS_DATA_DIR` stay compatible with **0.8.4** and **0.7.x** (no auto migration).
