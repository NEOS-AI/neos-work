## Highlights

### FE ↔ BE contract

| Item | Notes |
|---|---|
| Web save hash field | Write response uses **`hash`** (not `contentHash`); revisions still use **`contentHash`** |
| Web lock 409 | Collab lock/selection (and file write) preserve envelope `data.holder` |
| Web mutate policy | POST/PUT/DELETE use non-throwing envelopes (`createRun` included); GETs may throw |
| Desktop run cancel | Cancel active chat run + status badge; abort SSE on cancel |
| Contract smoke CI | `pnpm e2e:contract` — write `hash`, lock 409 holder, peers/locks, cancel 409 |
| Multi-replica e2e | `pnpm e2e:multi-replica` (structural) / `:live` (Redis + two engines) |
| Shared run types | `ProjectRunStatus` / `ProjectRunSummary` / `isTerminalRunStatus` in `@neos-work/shared` |
| Wire Zod schemas | Write + collab envelopes (`parseProjectFileWriteResponse`, lock conflict, OpenAPI fragments) |
| Desktop write parse | `writeProjectFile` validates success `data.hash` via shared schema |
| Server wire assert | Dev/`NEOS_ASSERT_WIRE` asserts outbound write + lock envelopes |
| Stream multi-select types | `selectors` / `layerIds` on collab SSE client types |
| Shared path normalize | `@neos-work/shared` `normalizeProjectRelPath` — web, desktop, server locks |
| Shared live file types | `ProjectFileContent`, `ProjectFileWriteResult`, `ProjectFileEventPayload` |
| CLI MCP write | Maps server `hash` into adapter `contentHash` |
| verify-key errors | Catch path returns **HTTP 500** + `ok: false` |

### Collab / multi-replica

| Item | Notes |
|---|---|
| First-seen remote heartbeat | Server fans out synthetic `presence.join` for local SSE clients |
| Peers REST poll | Web + desktop: heartbeat + `GET …/collab/peers` every ~45s (first at 12s) |
| Locks / selections REST poll | Same tick: `GET …/collab/locks` + `…/selections` resync foreign locks & peer outlines |
| Leave reason | Toast/notice: left / timed out (idle) / disconnected |
| Idle / away avatars | `lastSeen` → muted avatar + badge in PresencePeersBar |
| Peer canvas frames | Explicit frames win per `sessionId` when merging measured outlines |

### Desktop

| Item | Notes |
|---|---|
| Run events SSE | `streamProjectRunEvents` → `GET /api/runs/:id/events/stream` (poll fallback) |
| Revision snapshot view | `getProjectRevision` + View preview before restore |

### Web

| Item | Notes |
|---|---|
| File revisions panel | List / View content / Restore for open file |
| Runs panel | List project runs, event history, cancel non-terminal runs |
| Settings API keys | Save/verify Anthropic + Google keys; masked list from daemon |
| Collab status (ops) | `GET /api/collab/status` panel — bus, nodeId, presence registry |
| Thin client remains | Marketplace still desktop-first |

Auth / data under `NEOS_DATA_DIR` stay compatible with **0.8.6** and **0.7.x** (no auto migration).
