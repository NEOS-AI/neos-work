### Track B — Multi-replica run events

With `NEOS_RUN_REGISTRY` not `off`:

| Path | Behaviour |
|---|---|
| Owner emits | `appendRunEvent` dual-writes to shared buffer |
| `GET /api/runs/:id/events` | Local first; else shared buffer if summary exists |
| `GET /api/runs/:id/events/stream` | Local poll unchanged; remote polls shared buffer |
| Sticky SSE | **Not required** for run event stream when registry healthy |

See [ops multi-replica](../ops/multi-replica-collab.md) · [sticky SSE](../ops/sticky-sse.md).
