## Highlights for operators

### Agent lock identity

```bash
NEOS_SHARED_EDIT=1 \
NEOS_SHARED_EDIT_AGENTS=1 \
  pnpm --filter @neos-work/server dev
```

- Create runs with the human’s collab `sessionId` (desktop/web pass presence id).  
- Agent HTTP/tool writes can inherit that session via run bind.  
- Default remains agent **bypass** when agents flag is off.

### Tool files

Issue tool tokens with `capabilities: ["files"]` and call
`POST /api/tools/files/write`. Same 423 shape as project file PUTs.

### Workers UI

Desktop nav opens **`/workers`**. Bookmark **`/harnesses`** still loads the same
Domain Workers page. API remains `/api/workers` only (harness HTTP still 410).

### Still out of scope

- Full **CRDT** multi-caret  
- Sticky SSE across replicas  
- Multi-tenant RBAC
