## Highlights

### Durable run event log

```text
{NEOS_DATA_DIR}/runs/{runId}/events.jsonl
```

Env: `NEOS_RUN_EVENT_LOG=auto|on|off`  
Wired into every `appendRunEvent` dual-write. GET/SSE events fall back to disk
when the Redis/memory buffer is empty.

### Multi-replica e2e

```bash
pnpm e2e:multi-replica        # structural (includes L9/L10 contracts)
pnpm e2e:multi-replica:live   # Redis + two engines: L9 events on B, L10 jsonl
```
