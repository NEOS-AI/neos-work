## Highlights for developers

### PR CI browser E2E (T3)

```bash
pnpm --filter @neos-work/server... build
pnpm exec playwright install chromium
pnpm e2e:browser
```

Boots engine + Vite via Playwright, then asserts:

1. Connect URL + token → `/projects`  
2. Create project → `/projects/:id`  
3. Seed `index.html` + open Design Editor  
4. Code edit + Save (dirty clears)  
5. Preview iframe `#hero` shows marker  

**Node.js 22+** required. Process journey and contract suites are unchanged:

```bash
pnpm e2e:contract
pnpm e2e:journey
```
