## Highlights for operators

### Canvas overlay default (behavior change)

Since **0.9.1**, free-canvas overlay is **on by default** for HTML-like files.

| Control | Effect |
|---|---|
| unset env + unset pref | **On** |
| `VITE_NEOS_CANVAS_OVERLAY=0` / `NEOS_CANVAS_OVERLAY=0` | Force **off** |
| Settings / editor toggle | Persists `localStorage['neos.canvasOverlay']` = `1`/`0` |

Auth / SQLite / media under `NEOS_DATA_DIR` stay compatible with **0.8.x** and
earlier **0.9.x** (no auto migration).

### Web surface

Browser client covers the Design Project loop (editor, collab, comments, zip,
runs, API keys). **Not** included: workflow editor, marketplace install, media
studio, sessions — use desktop. See [dual-surface](../reference/dual-surface.md).

### Still out of scope

- Full **CRDT** multi-caret  
- Sticky SSE across replicas  
- Multi-tenant RBAC  
- Web marketplace install UI
