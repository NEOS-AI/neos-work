## Highlights for operators

### Multi-replica file SSOT

- Redis collab bus/registries do **not** sync project file bytes.  
- Prefer **single writer** for SQLite / Design Project mutates.  
- Shared volume is lab-friendly; multi-writer SQLite is **unsupported**.  

See [File content SSOT](../ops/multi-replica-collab.md#file-content-ssot-neos_data_dir).

### Sticky SSE

**Not shipped.** Design note explains when sticky helps (long-lived SSE pin,
run cancel locality) vs what already works via registries.  
[`docs/ops/sticky-sse.md`](../ops/sticky-sse.md)

### Still out of scope

- Full **CRDT** multi-caret  
- Sticky SSE implementation / shared run registry  
- Multi-tenant RBAC
