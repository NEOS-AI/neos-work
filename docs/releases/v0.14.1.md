## Highlights for developers

### PR CI process journey (T2)

```bash
pnpm --filter @neos-work/server... build
pnpm e2e:journey
```

Boots `apps/server/dist/index.js` with ephemeral data dir + Bearer auth. Covers
health, project create, file write `hash`, collab join, lock **409**, user
hard-enforce **423**, dry-run create/cancel. **Node.js 22+** required.

Contract suite is unchanged and still runs:

```bash
pnpm e2e:contract
```

### Nightly multi-replica L7

```bash
pnpm e2e:multi-replica:live
# or: NEOS_MULTI_REPLICA_E2E=1 pnpm e2e:multi-replica
```

With `NEOS_SHARED_EDIT=1` + `NEOS_SHARED_EDIT_AGENTS=1`, foreign **agent** PUT
on replica B returns **423** + holder from A (in addition to L5–L6 user path).

### Inventory

impl M1 + M3).
