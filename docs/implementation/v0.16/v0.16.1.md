# v0.16.1 Implementation

## Summary

**B0 — Shared run registry MVP.** Optional dual-write of lightweight run
summaries so multi-replica engines can answer `GET /api/runs/:id` and
`POST /api/runs/:id/cancel` when the live run lives on another process.
Local `RunRegistry` remains the source of truth for abort controllers and
event streams (no multi-node SSE fan-out in this slice).

Baseline: **0.15.0** / Track A may land as **0.16.0** in parallel

## Env

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_RUN_REGISTRY` | `auto` | Run summary store mode |
| `NEOS_COLLAB_BUS` | `memory` | When `redis`, auto prefers Redis summaries |
| `NEOS_COLLAB_REDIS_URL` / `REDIS_URL` | unset | Redis for bus + registries + run store |

```bash
NEOS_COLLAB_BUS=redis \
NEOS_COLLAB_REDIS_URL=redis://127.0.0.1:6379 \
NEOS_RUN_REGISTRY=auto \
  pnpm --filter @neos-work/server dev
```

### Modes

| Mode | Behaviour |
|---|---|
| `auto` | Redis when bus=redis **or** Redis URL present and `redis` connects; else memory mirror |
| `memory` | In-process summary map (single process / tests) |
| `redis` | Force Redis key + cancel channel (stub if URL/package fail) |
| `off` | No dual-write — pre-v0.16 local-only behaviour |

## Redis keys

| Key / channel | Type | TTL |
|---|---|---|
| `neos:run:summary:{id}` | string JSON summary | ~3600s |
| `neos:run:commands` | pub/sub cancel intents | — |

### Summary payload

`id`, `status`, `nodeId`, `projectId`, `collabSessionId`, `agentId`, `error`,
`createdAt`, `startedAt`, `completedAt`, `updatedAt`.

---

## Behaviour

| Path | Behaviour |
|---|---|
| `POST /api/runs` | Create local run; dual-write summary (running or terminal dry-run) |
| Status transitions in CLI execute | Best-effort dual-write after terminal / fail |
| `GET /api/runs/:id` | Local registry first; else shared summary (`eventCount: 0`) |
| `POST /api/runs/:id/cancel` | Local cancel + dual-write; else publish cancel + mark canceled |
| Owner node | `onCancelCommand` → `RunRegistry.cancel` + dual-write |
| Events / SSE | Unchanged — local only |

### Node identity

Reuses collab bus `nodeId` when the bus is initialized; otherwise a stable
process-random hex id at first use.

## Residual limits

| Limit | Detail |
|---|---|
| Events not shared | Non-owner GET has `eventCount: 0`; stream still 404s off-owner |
| Memory mode not multi-process | Only Redis (or injected shared map in tests) spans pods |
| Best-effort cancel | If owner is dead, store marks canceled; no process to abort |
| List endpoint | `GET /api/runs` still local-only (no shared index) |
