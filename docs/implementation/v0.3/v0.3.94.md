## Changes

### Task 1: Graph / preflight

- topologicalSort: max 2_000 nodes / 10_000 edges
- Skip control-char / overlong (>200) node and edge ids
- Preflight: `too_many_nodes`, `too_many_edges`, `invalid_node_id`

### Task 2: MCP OAuth / runtime / errors

- OAuth access/refresh tokens capped at 16 KiB; scope 1k; serverId 200
- Runtime auth token: reject control chars; max 8_192
- safeError log context ≤ 100 / message ≤ 4k; escapeHtml input ≤ 50k

### Task 3: LLM adapters

- OpenAI/Anthropic/Google: invalid model → first known model
- Cap conversation messages at 200; per-message content 500k (OpenAI/Anthropic/Google)
- Anthropic/Google system prompt capped at 100k

### Task 4: Memory tools / block / deploy / harness

- Memory tags: max 50 × 100 chars; recall query control-char reject / 2k cap
- BlockNode: invalid blockId/skillId; param keys control-char/length/count
- DeployNode: content max 2 MiB before fetch
- Harness POST: name control-char/length; map create errors to 400

### Task 5: Unit tests

- Graph max nodes/edges; control-char ids
- Preflight too_many_nodes
- Memory recall tags/query

- OAuth token caps; safeError/escapeHtml caps; runtime token
