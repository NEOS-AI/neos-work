## Changes

### Task 1: WorkerRuntime (`packages/core/src/agent/worker-runtime.ts`)

- `runWorker` / `WorkerRuntime.run`
- Events: `worker.started` | `worker.progress` | `worker.completed` |
  `worker.failed` | `agent` (orchestrator bridge)
- Timeout via worker `constraints.timeoutMs` (hard cap 30m) + host AbortSignal
- Goal/inputs/system prompt size caps aligned with orchestrator

### Task 2: Permission profiles & tool aliases

- `toolsForPermissionProfile`: read_only / read_write / execute / network / full
- `canonicalizeToolName`: `list_files`→`list_directory`, `shell`→`run_command`
- `resolveWorkerToolNames`: profile ∩ allowedTools; coordinator mode forces
  least-privilege (no write/shell when high profile)

### Task 3: Workspace isolation

- `resolveWorkerWorkspace`:
  - `none` → `process.cwd()`
  - `run` → `<base>/<runId>/[subdir]`
  - `isolated` → `<base>/<runId>/<workerRunId>/`
- Path segment sanitization (no `..` / separators)
- `buildWorkerToolRegistry` roots FS + shell tools at workspace; write outside
  fails closed

### Task 4: Prompt assembly

- `buildWorkerSystemPrompt`: worker prompt + node append + design context +
  memory (null-byte drop, size caps)

### Task 5: AgentNode wiring

- Replaces ad-hoc `createFilesystemTools(process.cwd())` registry with
  `resolveWorkerWorkspace` + `buildWorkerToolRegistry` so worker
  `permissionProfile` / `workspace` apply on graph agent nodes

### Task 6: Version

- monorepo **0.3.189 → 0.3.190**
- health / server banner / web_search User-Agent / MCP client version
