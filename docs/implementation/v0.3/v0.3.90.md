**harness systemPrompt size cap**, **ZIP import 50 MiB limit** (Task 10),
**KIS symbol charset/control-char reject** (finance blocks), **LLM maxTokens

- Cap content at 1 MiB; name ≤ 200 chars; reject control-char names
- Update rejects oversized content/name (row unchanged)
- `exportMemories` capped at 32 KiB with truncation marker

### Task 2: Custom harnesses

- systemPrompt ≤ 100_000 chars (create throw / update null)
- Description truncated at 2_000 chars

### Task 3: Workflow ZIP import (Task 10)

- Cap upload at 50 MiB (Content-Length + buffer length)

### Task 4: Finance KIS symbols

- Reject blank, control chars, non-alnum (except `._-`), length > 16

### Task 5: LLM adapters (multi-LLM)

- Clamp `maxTokens` to 1–128_000 (invalid → 4096) for OpenAI, Anthropic, Google

### Task 6: Skills / crystallize / plugin

- Skill upsert: reject control-char names/paths; name ≤ 200
- Crystallize description capped at 4_000 chars
- Plugin HITL JSON response capped at 200 KiB

### Task 7: Unit tests

- Memory content/name/export caps
- Harness oversized systemPrompt
- KIS invalid symbols
- OpenAI maxTokens clamp

### Task 8: Version

- monorepo **0.3.89 → 0.3.90**
