- New helper (mirrors Deployments `safeDeployUrl`)

- Exported for unit tests

- Post-connect 3s poll wrapped in try/catch — status probe throw never becomes unhandled rejection

### Task 3: Unit tests

- `safeOAuthAuthUrl` allow/reject matrix
- Non-http(s) authUrl does not call shell open
- Poll throw after successful open keeps server list; no error banner
- **44 passed** (Settings suite)
