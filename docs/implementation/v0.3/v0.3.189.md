## Changes

### Task 1: Domain Pack modules

- `packages/workflow-engine/src/packs/{finance,coding,research,general}.ts`
  - **finance** (4): `finance_analyst`, `finance_risk`, `finance_chart_analyst`,
    **`finance_portfolio`** (new) + block id ownership
  - **coding** (4): `coding_reviewer`, `coding_test_writer`, `coding_refactor`,
    **`coding_implementer`** (new, isolated workspace, execute)
  - **research** (2, Q4): **`research_web`**, **`research_synthesizer`**
  - **general** (2): **`general_generalist`**, **`general_coordinator`**
    (`defaultMode: coordinator`, `maxSpawnedWorkers: 4`)
- Each worker carries `permissionProfile`, `workspace`, `defaultMode` (v0.4 fields)

### Task 2: Pack / worker registry API

- `resolveWorker` / `listWorkers` / `registerWorker`
- `listPacks` / `resolvePack` / `isBuiltInPackId` / `BUILT_IN_PACK_IDS`
- Registration hygiene: control-char rejection, domain whitelist
  (`finance|coding|research|general`, else → general), profile/workspace/mode
  normalization, preferredBlockIds filter
- Public exports from `@neos-work/workflow-engine`

### Task 3: Harness compatibility layer

- `harness/*` re-exports packs (`FINANCE_HARNESSES` = `FINANCE_WORKERS`, etc.)
- `resolveHarness` / `listHarnesses` / `registerHarness` → worker registry aliases
- `AgentNode` resolves via `resolveWorker` (workerId / harnessId)

### Task 4: Tests & misc

- `packs/index.test.ts`, `packs/packs.test.ts`, harness catalog expectations
  updated for 4 finance / 4 coding workers
- Block meta `normalizeDomain` accepts `research`
- monorepo **0.3.188 → 0.3.189**
- health / server banner / web_search User-Agent / MCP client version

### Residual polish (same ship)

- `AgentNode` uses `import * as packs` so vitest can spyOn `resolveWorker`
  (named import broke the null-byte harness prompt unit test)
- `isBuiltInPackId` rejects control-char ids (align with `resolvePack`)
- Implementation notes for v0.3.187–189 live under `docs/implementation/v0.3/`
