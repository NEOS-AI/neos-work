- Skill parser: name control-char; description/body/triggers/example caps

- Pipeline stages max 20; stage id/name/prompt caps; skillContent ≤ 500k
- Plugin upgrade: skillDirName control-char; name 200 / description 2k
- AgentNode systemPrompt ≤ 100k; CLI inputs JSON ≤ 256 KiB

### Task 4: Shell / MCP / web search / context / CLI / artifacts / settings

- Artifact preview capped at ARTIFACT_CONTENT_MAX_CHARS
