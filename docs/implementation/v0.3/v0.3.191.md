## Changes

### Task 1: NodeContext bridge

- `onWorkerEvent` on `NodeContext` with started/progress/completed/failed payload
- Executor wires bridge → SSE `worker.*` (id hygiene + progress/output caps)

### Task 2: AgentNode worker lifecycle

- Emits `worker.started` before CLI spawn / orchestrator loop
- Progress chunks dual-publish: `node.progress` (existing) + `worker.progress`
- Completes / fails with matching worker events
- `workerId` from resolved worker (`workerId`/`harnessId`); fallback `ad_hoc_agent`
- `mode` from config or worker `defaultMode` (tool registry least-privilege for
  coordinator profile; spawn tools still Task 6)
- CLI solo path regression preserved

### Task 3: Tests

- Residual: LLM-path `onWorkerEvent` sequence + host-handler throw isolation;
  migrate-workflow pack inference / null config / v2 idempotent cases;
  WorkerRuntime failure terminals (`worker-runtime-fail.test.ts`)

- monorepo **0.3.190 → 0.3.191**
- health / server banner / web_search User-Agent / MCP client version
