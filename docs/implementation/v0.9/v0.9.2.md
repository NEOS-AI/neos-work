## Client API

```ts
listPreviewComments(projectId, filePath?)
createPreviewComment(projectId, { filePath, selector, body })
deletePreviewComment(projectId, commentId)
exportProjectZip(projectId) → { ok, blob } | { ok: false, error }
importProjectZip(zip) → envelope { project, filesImported? }
```

- Comment create validates control chars / empty fields (no fetch).  
- Zip import rejects **> 50 MiB** client-side.  
- Zip export uses raw body (`application/zip`), not JSON envelope.
