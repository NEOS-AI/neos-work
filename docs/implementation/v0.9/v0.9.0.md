## API

```ts
reorderSiblingInHtml(
  html,
  { neosId?, selector? },
  { toIndex? | beforeNeosId? | afterNeosId? | beforeSelector? | afterSelector? },
): { html, ok, reason? }
```

| `reason` | Meaning |
|---|---|
| `locked` | Source has `data-neos-locked` |
| `different-parent` | Target not under same parent |
| `not-found` / `target-not-found` | Identity miss |
| `no-op` | Already in place |
| `invalid-input` / `no-domparser` | Guard |

Prefer **`data-neos-id`** (stamp via existing `stampNeosIds` when missing).

## UX

```text
Layers drag ⋮⋮
    │ same parent only
    ▼
before / after drop (row mid Y)
    │
    ▼
reorderSiblingInHtml → onEdit(html) → bridge clear + reloadKey++
```

- Filter active → reorder off (`data-reorder="0"` + hint)  
- `source` jsx / jsx-partial → reorder off  
- Drop indicators: inset accent bar (`data-drop-before` / `data-drop-after`)
