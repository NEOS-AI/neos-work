## Precedence (canvas on?)

1. Explicit `canvasOverlay` prop on `DesignEditor`  
2. Env `NEOS_CANVAS_OVERLAY` / `VITE_NEOS_CANVAS_OVERLAY` (`0`/`false` off, `1`/`true` on)  
3. `localStorage['neos.canvasOverlay']` (`1`/`0`)  
4. **Default: on**

```ts
import {
  isCanvasOverlayEnabled,
  writeCanvasOverlayPref,
  CANVAS_OVERLAY_PREF_KEY,
} from '@neos-work/design-editor';
```

## Align / z-order

| Tool | Requirement | Write path |
|---|---|---|
| Align edges | Multi-select ≥ 2 + bboxes | `left`/`top` deltas vs **primary** |
| Distribute H/V | Multi-select ≥ 3 + bboxes | Even spacing between first/last |
| Z-order | Selection (primary) | DOM sibling order (`applyZOrderInHtml`) |

Align needs measured bboxes (Inspect / Preview select). Layer-only multi without
bbox disables align buttons.
