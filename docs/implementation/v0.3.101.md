# v0.3.101 Implementation

## Summary

PLAN_FOR_V0_3_0 residual polish: **shared `safeRouteId` path-param hygiene**
across remaining REST routes (Task 16 / API surface), **artifact DB + route

## Changes

### Task 1: Shared route id helper

- `safeRouteId` + `ROUTE_ID_MAX_CHARS` in `path-safety.ts`
- Reject blank, control-char (`\0`/`\r`/`\n`), overlong (>100) path/query ids
- Artifacts / workflow-revisions local helpers delegate to shared helper

### Task 2: Route path-param hygiene

- Artifacts: refresh uses safeId; create rejects unsafe runId/nodeId;
  validation errors (max length / invalid / control chars) → 400
- Workflow / session `paramId` via `safeRouteId` (toolUseId max 200)
- Memory, deploy, routines, skills, plugins, harness, MCP server/oauth ids
- Blocks: alphanumeric id shape + length/control-char reject
- Deploy list: drop unsafe `workflowId` query filter

### Task 3: Artifact DB layer

- Null-byte content reject on create/update
- Cap workflowId / runId / lookup ids at 100; nodeId at 200 (GRAPH_ID_MAX_CHARS)
- Drop invalid optional runId/nodeId (null); reject unsafe/overlong filePath
- list/get/delete/update use shared lookup id hygiene

### Task 4: Slack / healing / shell / LLM keys

- SlackMessageNode: bot token control-char reject; max 8_192
- ReflectionStrategy: description ≤ 2k; unsafe tool names dropped;
  revisedInput plain-object + 16k JSON cap
- Shell tool: cwd max 4_096 chars
- OpenAI/Anthropic/Google: validateApiKey rejects control-char / overlong keys

### Task 5: Unit tests

- safeRouteId unit cases
- Memory / artifact control-char & overlong path ids
- Artifact invalid runId/nodeId on create; null-byte content; filePath
- LLM constructor / validate key control-char/overlong cases
- Slack token control-char/overlong
- Shell overlong/control-char cwd
- Healing revised tool drop + description cap

### Task 6: Version

- monorepo **0.3.100 → 0.3.101**
- health / server banner / web_search User-Agent / MCP client version
