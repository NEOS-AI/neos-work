# v0.21.0 Implementation — Track 1 durable run event log

## Summary

**Track 1 — Durable run event JSONL.** Best-effort append-only log under
`{NEOS_DATA_DIR}/runs/{runId}/events.jsonl` so multi-replica engines sharing a
volume can recover events after Redis buffer TTL/eviction or restart.

Baseline: **0.20.0** / shared run event buffer (0.19)

---

## Env

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_RUN_EVENT_LOG` | `auto` | `auto` \| `on` \| `off` |

## API

```ts
appendRunEventLog(runId, event): boolean
readRunEventLogAfter(runId, afterEventId?): RuntimeRunEvent[]
runEventLogStatus(): { mode, enabled, root }
```

`dualWriteRunEvent` writes JSONL then shared buffer.

GET `/api/runs/:id/events` (non-local): shared buffer first; if empty, durable
log; if summary missing but log non-empty, still return durable events.
