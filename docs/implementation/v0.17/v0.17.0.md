# v0.17.0 Implementation — M0 EngineMediaClient

## Summary

**M0 — Skills + media + live artifacts client extract.** Moves skills, media
generation/files/jobs, and live-artifacts APIs off `EngineClient` into
`EngineMediaClient`, matching the v0.12 / v0.16 hierarchy pattern.

Baseline: **0.16.2**  
Scope: desktop `apps/desktop/src/lib` only (no agent-runtime, server, e2e).

## Hierarchy

```text
EngineTransport
  → EngineProjectClient
    → EngineWorkflowClient
      → EngineSettingsClient
        → EngineMediaClient   // NEW (v0.17 M0)
          → EngineClient      // remaining domains
```

| Class | Role |
|---|---|
| `EngineTransport` | baseUrl, auth, headers, path segments |
| `EngineProjectClient` | design projects, collab, files, runs |
| `EngineWorkflowClient` | workflows, deploys, webhooks, blocks |
| `EngineSettingsClient` | settings, connection-test, MCP |
| `EngineMediaClient` | skills, media files/generate/jobs, live artifacts |
| `EngineClient` | health, sessions, chat, agent, workspaces, design systems, artifacts, routines, plugins, … |

Call sites keep `import { EngineClient, SkillData } from '../lib/engine.js'`.

---

## Methods on `EngineMediaClient`

**Skills:** `listSkills`, `scanSkills`, `toggleSkill`, `deleteSkill`, `upgradeSkillToPlugin`

**Media:** `deleteMediaFile`, `listMediaFiles`, `generateMedia`, `getMediaConfig`,
`listMediaProviders`, `getMediaJob`, `fetchMediaBlob`

**Live artifacts:** `listLiveArtifacts`, `createLiveArtifact`, `refreshLiveArtifact`,
`deleteLiveArtifact`

Shared types `MediaFileInfo`, `LiveArtifact`, `LiveArtifactRefresh`, `Plugin` remain
on `engine-project` and are imported by `engine-media.ts`.
