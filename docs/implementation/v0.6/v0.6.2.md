```bash
VITE_NEOS_CANVAS_OVERLAY=1 pnpm --filter @neos-work/web dev
VITE_NEOS_CANVAS_OVERLAY=1 pnpm --filter @neos-work/desktop dev

# Or globalThis / process
NEOS_CANVAS_OVERLAY=1 …
```

Prop override: `<DesignEditor canvasOverlay />` forces on.

---

## Behavior

1. Badge **Canvas** in editor toolbar when enabled (HTML paths only).  
2. Inspect (or auto-inspect while canvas on) → select element → bbox from bridge.  
3. Drag purple **Move** frame → accumulates `left`/`top` px; sets `position: relative` if static.  
4. Prefer `data-neos-id` rewrite; fallback `#id`. Stamps neos ids if needed.  
5. Calls host `onEdit` — same dirty/save path as Code edits.

**Non-goals (still M3+):** multiplayer co-edit of transforms, free-draw vectors, auto-layout.
