## Protocol

| API | Role |
|---|---|
| `GET …/collab/stream` | `presence.sync` includes `locks[]`; + `lock.acquired` / `lock.released` |
| `GET …/collab/locks` | Snapshot + `hardEnforce` flag |
| `POST …/collab/locks` | `{ sessionId, path, action: acquire\|release }` |
| `PUT …/files/*` | If `NEOS_SHARED_EDIT=1` and lock held by other → **423** |

Locks are ephemeral (memory). Leave/idle/evict releases all locks for that session.

---

## Client UX

- On open file: best-effort `acquire` for collab session  
- On path change/unmount: `release`  
- Banner **Locked by {name}** when another session holds the open path  

---

## Enable hard mode

```bash
NEOS_SHARED_EDIT=1 pnpm --filter @neos-work/server dev
# Client should send X-Neos-Session-Id or body.sessionId matching lock holder
```

Default remains **advisory** (LWW still wins if hard mode off).
