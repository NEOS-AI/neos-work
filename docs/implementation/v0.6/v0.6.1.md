## Awareness UX

### Server
- Peers include stable `colorHint` (0–359) for avatar hues
- `lastSeen` + `sweepIdlePresence` (90s idle → `presence.leave` reason `idle`)
- SSE loop calls `touch()` each second; sweeps every ~15s
- `GET /api/projects/:id/collab/peers` — peer snapshot
- `POST /api/projects/:id/collab/heartbeat` `{ sessionId }`

### Clients (`@neos-work/ui-app`)
- **`PresencePeersBar`**: stacked initials avatars, Solo / N peers, popover list with self + others
- Wired in web `ProjectDetail` and desktop `ProjectWorkspace`

## JSX Layers

`packages/design-editor/src/jsx-layers.ts`:

| Export | Role |
|---|---|
| `isJsxPath` | `.jsx` / `.tsx` |
| `extractJsxReturnSnippet` | primary `return` JSX |
| `jsxSnippetToPseudoHtml` | className→class, strip `{expr}`, PascalCase → `jsx-*` |
| `parseJsxToLayerTree` | DOMParser tree + `incomplete` flag |

**DesignEditor:** shows Layers for HTML *and* JSX paths; source badge `JSX` or `JSX~` when expressions stripped / partial.
