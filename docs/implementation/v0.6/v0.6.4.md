## Catalog schema (`neos-marketplace/v1`)

```json
{
  "schemaVersion": "neos-marketplace/v1",
  "name": "My catalog",
  "entries": [
    {
      "id": "my-plugin",
      "name": "My Plugin",
      "version": "1.0.0",
      "trust": "official|community|unverified",
      "packageUrl": "https://…/open-design.json",
      "sha256": "optional-hex-64"
    }
  ]
}
```

Sample: `e2e/fixtures/marketplace/sample-catalog.json`

## API

| Method | Path | Role |
|---|---|---|
| GET | `/api/marketplace/catalog-url` | configured URL |
| PUT | `/api/marketplace/catalog-url` | set/clear URL |
| GET | `/api/marketplace/catalog?url=` | fetch + parse |
| POST | `/api/marketplace/install` | `{ id }` or `{ entry }` |

Install writes `~/.config/neos-work/skills/<id>/open-design.json` (+ `neos-remote.json` provenance).

## Security

- Catalog & package URLs: `fetchPublicHttp` + DNS public check  
- Private/metadata hosts blocked  
- Size caps; id path-safe; symlink install target refused  
- Unverified installs require UI confirm
