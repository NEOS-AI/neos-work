## Presence protocol (M0)

| Event | Payload (high level) |
|---|---|
| `ready` | `{ projectId, sessionId }` |
| `presence.sync` | `{ self, peers[] }` on connect |
| `presence.join` | `{ peer }` |
| `presence.leave` | `{ sessionId }` |

- Connection open = join; abort/close = leave  
- Query `?name=` sanitized display label  
- Max 32 peers/project; oldest dropped under pressure  
- No host paths / secrets in events
