# v0.15.0 Implementation

## Summary

**M2 — Playwright browser Design Project loop.** Adds `e2e/browser/` behind
`pnpm e2e:browser`: boots the real built server + Vite web, then exercises the
Web Connect → create project → Code edit → Save → Preview path in Chromium.
Wired into PR CI after server build and `playwright install chromium`.

## What landed

| Piece | Detail |
|---|---|
| Runner | `e2e/browser/run.mjs` — T3 browser E2E entry (Node 22+, dist check, `playwright test`) |
| Config | `e2e/browser/playwright.config.ts` — engine + Vite `webServer`, Chromium |
| Spec | `e2e/browser/specs/design-project.spec.ts` — Connect → create → edit → save → preview |
| Script | root `package.json` → `"e2e:browser": "node e2e/browser/run.mjs"` |
| CI | `.github/workflows/ci.yml` — build server, `playwright install chromium --with-deps`, browser e2e |
| Engines | Fail fast if Node major &lt; 22; clear rebuild hint if dist missing |

### Browser golden path (asserted)

| # | Step | Expected |
|---|---|---|
| 1 | Connect URL + token | lands on `/projects` |
| 2 | Create project | navigates to `/projects/:id` |
| 3 | Seed `index.html` (API) + reload | file in tree; Design Editor open |
| 4 | Code mode edit + Save | dirty clears; no error alert |
| 5 | Preview mode | iframe `#hero` shows marker text (`browser-e2e-ok`) |

Test IDs used include `connect-submit`, `project-create-*`, `design-editor`,
`mode-code`, `save-button`, `mode-preview`, `preview-frame`.
