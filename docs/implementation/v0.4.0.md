## Breaking changes (user-facing)

1. Node types `agent_finance` / `agent_coding` → **`agent` + workerId** (auto on load).
2. Workflow **`schemaVersion: 2`**, **`primaryDomain`** (DB column still `domain`).
3. Custom harness table **`workers`**; API **`/api/workers`** (harness routes deprecated).
4. SSE adds **`worker.*`** and **`node.warning`**.
5. New built-in pack **research** and workers (portfolio, implementer, coordinator, …).

Full guide: [`docs/migration/v0.4.0.md`](../migration/v0.4.0.md).
