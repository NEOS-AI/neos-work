# v0.14.0 Implementation

`pnpm e2e:journey`: boots the real built server (`apps/server/dist/index.js`)
with ephemeral `NEOS_DATA_DIR` + Bearer auth, then exercises the Design Project
HTTP path that clients depend on. Wired into PR CI after a server filter build.

### Journey steps (asserted)

| # | Step | Expected |
|---|---|---|
| 1 | Node engines | major ≥ 22 |
| 2 | `GET /api/health` | **200** + Bearer |
| 3 | `POST /api/projects` | **201** + `data.id` |
| 4 | `PUT …/files/index.html` | **200** + `hash` (not `contentHash` on data) |
| 5 | Collab SSE ready ×2 | `sessionId` peers |
| 6 | Lock B after A | **409** + holder |
| 7 | Foreign user PUT (`NEOS_SHARED_EDIT=1`) | **423** + holder |
| 8 | Holder user PUT | **200** |
| 9 | Dry-run create + cancel | ok; second cancel **409** if terminal |

Agents flag stays off for the user-only 423 case; agent wire remains covered by
`pnpm e2e:contract` (and multi-replica L7 in 0.14.1).
