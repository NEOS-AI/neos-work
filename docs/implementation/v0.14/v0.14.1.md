## Live L7

`e2e/multi-replica/run.mjs` (live mode) sets both replicas with:

- `NEOS_SHARED_EDIT=1`
- `NEOS_SHARED_EDIT_AGENTS=1`
- shared locks via `NEOS_COLLAB_LOCKS=auto` (Redis)

After lock acquire on A and user foreign **423** on B (L6):

| Assert | Expected |
|---|---|
| Agent PUT on B, no holder session | **423** |
| `data.holder.sessionId` | session A |

PR CI still runs structural multi-replica only; live remains nightly
(`.github/workflows/nightly-multi-replica.yml`).
