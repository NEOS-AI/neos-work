## Changes

### Task 1: Safe JSON parse (DB rows)

- Harnesses: corrupt `allowed_tools_json` / non-object `constraints_json` → `[]` / `{}`
- Blocks: corrupt / non-array `param_defs_json` → `[]`
- Routines: corrupt / non-object `inputs_json` → `{}`; create/update coerce non-object inputs
- MCP servers / session: corrupt `args` JSON → `null` / omit
- Workflows runs: corrupt nodes/edges/nodeResults covered by tests (v0.3.86 parsers)

### Task 2: Custom blocks (Task 12)

- Export `normalizeImplementationType` (native|prompt|skill; unknown → native)
- Create/update persist normalized type; case-insensitive (` PROMPT ` → prompt)
- Domain list filter lower-cases allow-list (` CODING ` matches coding)
- `rowToBlock` normalizes legacy implementationType values

### Task 3: CLI spawn (Task 3)

- Reject control chars (`\0` / CR / LF) in prompt (after trim) and raw cwd
- Validate cwd exists and is a directory; skip unsafe path overrides
- Cap stream accumulation at 2 MiB

### Task 4: AgentNode memory (Task 14)

- Cap injected memory export at 32 KiB with truncation marker
- Prefer `AUTH_TOKEN`; fall back to `SERVER_TOKEN` (shared runtime token)

### Task 5: Plugin runner (Task 5)

- Non-ok Anthropic/OpenAI responses include truncated body (500 chars)
- Tolerate missing content arrays / message fields

### Task 6: Memory / deploy / media

- Memory DB: reject control chars in key/workspaceId; strip control-char tags
- Memory store `parseFile`: normalize frontmatter type via allow-list
- Deployments create/update: only persist http(s) URLs via `safeDeployHostUrl`
- Image download: Content-Length pre-check before buffering (16 MiB)

### Task 7: Unit tests

- Block implementationType normalize + corrupt param_defs
- Harness corrupt tools/constraints JSON; non-array updates
- Routine non-object / corrupt inputs
- Memory control-char keys/tags
- Deploy non-http URL reject; bare host → https
- CLI control-char prompt/cwd + missing cwd
- Agent memory truncation + SERVER_TOKEN fallback
- Plugin HTTP error body detail
- Executor runId / output truncate / blank node id
- Workflows corrupt nodes/edges/nodeResults
- Provider registry blank id ignore

### Task 8: Version

- monorepo **0.3.86 → 0.3.87**
- health / server banner / web_search User-Agent / MCP client version
