## Changes

### Task 1: Custom blocks DB

- `normalizeImplementationType`: native|prompt|skill; unknown → native
- Safe `paramDefs` JSON parse (non-array / corrupt → `[]`)
- Create/update normalize domain + implementationType
- Domain list filter case-folds (`CODING` → `coding`)

### Task 2: Custom harnesses DB

- Safe parse `allowed_tools_json` (array of trimmed strings) and
  `constraints_json` (object only)
- Create/update: non-array tools → `[]`; non-object constraints → `{}`

### Task 3: Routines DB

- Safe parse `inputs_json` (object only; arrays/primitives → `{}`)
- Create/update coerce non-object inputs to `{}`

### Task 4: Memory DB

- Reject `\0` / CR / LF in key and workspaceId on create
- Drop control-char tags; tag search ignores control-only filters
- Safe tags JSON parse (non-array → no match)

### Task 5: AgentNode memory injection

- Cap memory export injection at 32 KiB with truncation marker

### Task 6: Media generator

- Reject oversized image downloads early via `Content-Length` (16 MiB)

### Task 7: Deployments DB

- Persist only http(s) URLs via `safeDeployHostUrl` (bare host → https)

### Task 8: CLI agents

- Reject control chars in prompt/cwd; skip unsafe path overrides
- Validate cwd is an existing directory
- Cap accumulated CLI stdout/stderr at 2 MiB

### Task 9: Plugin runner / MCP / session

- Truncate Anthropic/OpenAI error bodies (500 chars)
- Safe MCP args JSON parse on list/response and session tool load

### Task 10: Unit tests

- memory control-char keys/tags
