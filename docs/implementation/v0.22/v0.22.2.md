# v0.22.2 Implementation — M2 nightly live multi-replica e2e

## Summary

**M2 — Wire live multi-replica e2e as a scheduled CI job** with Redis service,
one retry on flake, and structural gates for L11 + workflow presence.

## Workflow

`.github/workflows/nightly-multi-replica.yml`

- `schedule: 0 6 * * *` + `workflow_dispatch`  
- `services.redis: redis:7-alpine`  
- `pnpm e2e:multi-replica` then `pnpm e2e:multi-replica:live`  
- Retry step on failure with verbose logs  

PR CI remains **structural-only** (`ci.yml`) so PRs stay fast.
