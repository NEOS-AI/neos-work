# v0.22.1 Implementation — M1 durable run summary

## Summary

**M1 — `summary.json` next to `events.jsonl`.** Written on every
`dualWriteRunRecord` / `syncRunSummary`. Hydrates `GET /api/runs/:id` when local
registry and shared Redis summary miss.

## Layout

```text
{NEOS_DATA_DIR}/runs/{runId}/
  events.jsonl
  summary.json   # NEW
```

## Files

- `writeRunSummaryLog` / `readRunSummaryLog` in `run-event-log.ts`  
- `run-registry-shared.ts` dual-write summary to disk  
- `routes/runs.ts` GET fallback
