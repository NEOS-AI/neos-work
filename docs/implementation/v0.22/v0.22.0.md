# v0.22.0 Implementation — M0 run log retention

## Summary

**M0 — GC/retention for durable run logs.** Env caps + `pruneRunEventLogs()` on
server startup; optional per-file trim of `events.jsonl`.

## Env

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_RUN_EVENT_LOG_MAX_AGE_HOURS` | 168 | Delete run dirs older than N hours (`0` off) |
| `NEOS_RUN_EVENT_LOG_MAX_RUNS` | 500 | Keep at most N dirs, oldest first (`0` off) |
| `NEOS_RUN_EVENT_LOG_MAX_FILE_BYTES` | 8 MiB | Head-trim single events.jsonl |

## Files

- `apps/server/src/lib/run-event-log.ts` — prune + trim  
- `apps/server/src/index.ts` — log status + prune on boot  
- unit tests in `run-event-log.test.ts`
