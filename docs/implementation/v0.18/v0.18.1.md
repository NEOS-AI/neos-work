# v0.18.1 Implementation — M1 EnginePluginsClient

## Summary

**M1 — Plugins / marketplace / workers / domain-packs client extract.** Moves
marketplace catalog install, plugin list/run/resume, workers, and domain packs
off `EngineClient` into `EnginePluginsClient` (extends `EngineSessionsClient`).

Shipped together with M0 in monorepo **0.18.0**.

## Methods on `EnginePluginsClient`

**Marketplace:** `getMarketplaceCatalogUrl`, `setMarketplaceCatalogUrl`,
`fetchMarketplaceCatalog`, `installMarketplaceEntry`

**Plugins:** `listPlugins`, `runPlugin`, `resumePlugin`

**Workers / packs:** `listWorkers`, `listDomainPacks`, `installDomainPackFromPath`,
`installDomainPackFromZip`, `validateDomainPackManifest`, `getDomainPack`,
`toggleDomainPack`, `deleteDomainPack`, `createWorker`, `updateWorker`,
`deleteWorker`, `listHarnesses` (deprecated alias)

## Remaining on `EngineClient`

Design systems, artifacts, routines, deploy helpers, blocks, templates, memory.
