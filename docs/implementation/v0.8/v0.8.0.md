# v0.8.0 Implementation

## Summary

**v0.8 train opens — M0 shared presence membership.** Peers connected on other
engine replicas (via CollabBus) are mirrored into a membership store so
`presence.sync` and `GET …/collab/peers` include them. Lightweight
`presence.heartbeat` keeps remote entries alive; idle sweep drops stale remotes
without re-broadcasting leave.

## Architecture

```text
Node A SSE session ──► rooms (local) + membership(local)
         │ join / heartbeat / leave
         ▼
     CollabBus ──► Node B applyRemote
                      │
                      ├─ membership(remote) upsert/touch/remove
                      └─ deliver to local SSE (except heartbeat)
```

| Concept | Local | Remote |
|---|---|---|
| SSE listener | `rooms` | none |
| Peer list | membership | membership (mirrored) |
| Idle | `PRESENCE_LOCAL_IDLE_MS` (90s) → forceLeave + bus | `PRESENCE_REMOTE_IDLE_MS` (270s) → local leave only |
| Heartbeat | every ~30s on touch | refreshes membership |

## Limits

- Cold replica has empty membership until bus events arrive.  
- Without Redis bus, multi-process still needs `NEOS_COLLAB_BUS=redis`.  
- Single replica: behavior equivalent to v0.7 (membership mirrors local rooms).
