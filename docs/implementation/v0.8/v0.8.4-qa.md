## Local Node / native module note

Repo `engines.node` is **≥22**. If the shell default is Node **20** (or another
major) while `better-sqlite3` was built for **22** (or vice versa):

```
NODE_MODULE_VERSION 127 vs 115
```

**Fix:** `nvm use 22` (or install Node 22) then `pnpm rebuild better-sqlite3`
(or a clean `pnpm install`). Prefer rebuild over code workarounds.

**CI / recommended:** Node 22 + `pnpm install` so native modules match.
`.github/workflows/ci.yml` pins `node-version: '22'`.
