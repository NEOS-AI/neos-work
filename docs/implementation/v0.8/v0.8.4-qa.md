## Local Node / native module note

Repo `engines.node` is **≥22**. On this machine the shell default is often Node **20**, while `better-sqlite3` may be built for **22** (or vice versa):

```
NODE_MODULE_VERSION 127 vs 115
```

**CI / recommended:** Node 22 + `pnpm install` (or rebuild) so native modules match.  
Full `apps/server` vitest suite is green when ABI matches; collab-only suites do not need SQLite and pass regardless.
