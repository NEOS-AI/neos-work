## Architecture notes

### Error envelopes (web)

- Throwing `request()` attaches `ApiError.data` on 4xx/5xx.
- Collab lock/selection, write, delete, restore use non-throwing `requestEnvelope`
  so `data.holder` / error bodies survive.

### Collab resync

```text
SSE presence.* / lock.* / selection.*
        │
        ├─ heartbeat + GET peers + locks + selections (every ~45s)
        └─ first-seen remote heartbeat → presence.join (server)
```

### Run SSE (desktop)

```text
createProjectRun → streamProjectRunEvents
        │
        ├─ log run.stdout / run.failed / …
        └─ getProjectRun on stream end (+ poll fallback)
```
