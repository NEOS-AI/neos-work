## Behavior

| Selection | SE handle |
|---|---|
| Single | Resize width/height only (v0.7 M0) |
| Multi | Scale sx/sy from primary base+delta; each peer box scales size **and** position about primary TL |

```text
anchor = primary top-left (fixed)
sx = (primary.w + dw) / primary.w
sy = (primary.h + dh) / primary.h
box' = {
  x: anchor.x + (box.x - anchor.x) * sx,
  y: anchor.y + (box.y - anchor.y) * sy,
  w: box.w * sx,
  h: box.h * sy
}
```

Min size clamp: 8px.

## Usage

```bash
VITE_NEOS_CANVAS_OVERLAY=1 pnpm --filter @neos-work/web dev
```

1. Inspect/Layers: Shift+click multiple elements  
2. Drag SE corner on primary (solid) frame  
3. Dashed frames scale with the group; save writes all styles
