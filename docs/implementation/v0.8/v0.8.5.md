## 1. Uniform group scale

When **multi-select** resizing via the primary SE handle:

| Modifier | Behavior |
|---|---|
| none | Free `sx` / `sy` from `dw` / `dh` (v0.8.2) |
| **Shift** | `sx = sy` (dominant pointer axis chooses scale) |

Live preview (`CanvasOverlay`) and HTML apply (`computeGroupResizeScales` →
`applyGroupResizeToHtml`) share the same math. Single-select resize is unchanged
(independent width/height deltas).

```ts
computeGroupResizeScales(primary, dw, dh, { uniform: true })
// → { sx, sy, uniform: true, primaryNext }
```

`CanvasTransformEnd` resize payload may include `uniform?: boolean`.

## 2. Canvas transform undo

Lightweight **in-editor** stack for canvas moves/resizes only (not full history):

- Snapshot `buffer.local` **before** a successful canvas HTML apply
- Push on successful apply; clear redo; cap **20** (`CANVAS_UNDO_CAP`)
- **Cmd/Ctrl+Z** → undo; **Shift+Cmd/Ctrl+Z** → redo
- Ignores key events focused in CodeMirror / inputs
- Cleared on file path change

Does **not** replace CodeMirror undo or a global document history system.

## 4. Peer multi-select outlines

```ts
type PeerCanvasFrame = {
  colorHint: number;
  bboxes: CanvasBBox[];
  label?: string;
};

// CanvasOverlay
peerFrames?: PeerCanvasFrame[];

// DesignEditor
peerCanvasFrames?: PeerCanvasFrame[];
```

- Non-interactive dashed outlines colored by `colorHint` (`hsl(h 70% 55%)`)
- Optional label badge above first bbox
- Host must supply **measured** bboxes (no iframe query yet)
- Web/desktop may pass `[]` or omit; future presence wiring can fill frames when bboxes exist
- Without bboxes, existing PresencePeersBar chrome remains the peer indicator

---

## 5. JSX multi-select (best-effort)

- Layers Shift/meta/ctrl multi-select uses the same `handleLayerSelect` path for
  `.jsx` / `.tsx` files; `multiSelectors` still publish for collab when multi.
- **Limit:** canvas bbox multi + group scale require the **HTML bridge** (inspect
  click + measured bboxes). JSX parse layers have no live layout boxes, so canvas
  group chrome is HTML-only.
