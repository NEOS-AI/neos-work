## Protocol

```ts
// selection.changed / presence.sync.selections[]
{
  sessionId, displayName, colorHint,
  path: string | null,
  selector: string | null,      // primary
  layerId?: string | null,
  selectors?: string[],         // multi, ordered; last = primary
  layerIds?: string[],
  updatedAt
}
```

`POST /api/projects/:id/collab/selection`:

```json
{
  "sessionId": "…",
  "path": "index.html",
  "selector": "#b",
  "selectors": ["#a", "#b", "#c"],
  "layerIds": ["n1", "n2", "n3"]
}
```

- Max 32 selectors; invalid/control-char dropped; deduped.  
- Primary = last entry when `selectors` provided.

## Client

- DesignEditor embeds `multiSelectors` / `multiLayerIds` on `SelectionState` when multi.  
- Web/desktop debounced publish includes multi when length > 1.  
- Peers bar: `index.html · 3 sel · #c`
