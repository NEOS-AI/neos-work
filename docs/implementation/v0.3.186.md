## Changes

### Task 1: EngineClient path hygiene

- `sanitizeId`: shared fail-closed trim (control-char / blank / overlong /
  path separators / bare `.` / `..`); `pathSegment` encodes the result
- `getSetting` / `saveSetting`: `settingKeySegment` (server-aligned: alnum /
  `_` `.` `-`, max 100)
- `upgradeSkillToPlugin` / `createRoutine` / `createSession`: sanitize body ids
- Media: `mediaFilenameSegment` aligned with server `isSafeMediaFilename`
- `mediaAuthHeaders`: control-char-safe Authorization for delete/fetch blob
- `runPlugin`: invalid plugin id → `{ type: 'error' }` event, no fetch
- `listArtifacts` / `listDeployments`: explicit fail closed on bad/missing ids

### Task 2: WorkflowEditor schedule create

- Gate `workflow.id` with `safeEntityId` before `createRoutine`

### Task 3: Routines

- `listRoutineRuns` load: gate `selectedId` (no API on dirty id)
- Create form: `safeEntityId(formWorkflowId)` instead of control-char-only check
- Invalid-id load path avoids null↔error render loop when `client` identity
  changes each render

### Task 4: Unit tests

- EngineClient: settings charset/length, skill upgrade, createRoutine/Session,
  media rejection, runPlugin invalid-id event
- WorkflowEditor / DesignSystemEditor / Routines / RevisionPanel dirty-id gates
- RunHistoryPanel: overlong/control id empty chrome (no clear buttons)
- Related suites green
