## Changes

### Task 1: Export v2 document shape

- `GET /api/workflow/:id/export` and `export.zip` include:
  - top-level `schemaVersion: 2`
  - `workflow.schemaVersion`, `primaryDomain`, `domain` (same pack id),
    optional `domainPackIds`, nodes/edges (already migrated on load)
- Helper `exportableWorkflowDoc` keeps export/import aligned with Q2

### Task 2: Import + migrate API

- Import prefers `primaryDomain` over `domain`; pack set includes **research**
- Optional designSystemId applied after create
- **`POST /api/workflow/migrate`**: dry-run by default (`dryRun: true`);
  returns `{ neededMigration, report, workflow }`; `dryRun: false` + `id`
  persists nodes/edges to an existing workflow

### Task 3: UI package build reliability

- `@neos-work/ui` `build`: `rm -rf dist && tsc` so incremental/composite never
  skips JS emit (v0.4.0 desktop vite failure fix)

### Task 4: Version

- monorepo **0.4.0 → 0.4.1**
- health / server banner / web_search User-Agent / MCP client version

### Residual polish

- `POST /api/workflow/migrate` with `dryRun: false` requires `id` (no silent dry-run)
- Implementation notes only under `docs/implementation/v0.4/` (not root)
- **`unregisterWorker`**: DELETE `/api/workers/:id` (and harness alias) drops the
  custom worker from the in-memory registry so list/get no longer resurrect it
