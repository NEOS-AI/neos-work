## Changes

### Task 1: Engine client worker CRUD

- `createWorker` / `updateWorker` / `deleteWorker` → `POST/PUT/DELETE /api/workers`
- Deprecated `createHarness` / `updateHarness` / `deleteHarness` delegate to worker methods
- `listHarnesses` still prefers workers with harness alias fallback (older servers)

### Task 2: Workers page (route `/harnesses`)

- Load via `listWorkers` (not harness alias alone)
- Create/update/delete via workers API
- Domain select includes **research**
- Form fields: `permissionProfile`, `defaultMode`, `workspace`
- Cards show profile chip + coordinator badge
- Server-generated ids (no client id field on create)
- Search / empty copy: “workers”

### Task 3: i18n + migration doc

- en/ko `nav.harnesses` + `harness.*` strings → Workers / 워커
- New keys: `permissionProfile`, `defaultMode`, `workspace`
- `docs/migration/v0.4.0.md`: `domain_pack_ids_json` noted as present since 0.4.2

### Task 4: Version

- monorepo **0.4.2 → 0.4.3**
- health / banner / web_search UA / MCP client version
