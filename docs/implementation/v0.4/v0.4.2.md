- `createWorkflow` / `updateWorkflow` serialize pack id arrays
- `rowToWorkflow` merges stored packs with migrate-inferred packs
- Omits storage when only `['general']`

### Task 2: API create / update

- `POST /api/workflow` accepts `primaryDomain` (preferred) + `domainPackIds`
- Create domain pack set includes **research**
- `PUT /api/workflow/:id` accepts `primaryDomain` / `domain` / `domainPackIds`
- Auto-revision snapshots include `schemaVersion`, `primaryDomain`, `domainPackIds`

### Task 3: Revision restore

- Pre-restore + restore apply domain + domainPackIds from snapshot
- `updateWorkflow` migrates nodes (existing path) so legacy agent_* rewrites
