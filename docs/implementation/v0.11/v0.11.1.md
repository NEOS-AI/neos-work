## UI surfaces

### Settings (desktop + web)

`GET /api/collab/status` panel now shows:

- **locks** registry `kind` · ready (in addition to bus / presence)
- **shared-edit** `on|off` and, when on, **agents on|off**

Test ids: `collab-status-locks`, `collab-status-shared-edit`

### Design Project header

When locks snapshot reports `hardEnforce`:

- Badge `locks: enforce` or `locks: enforce + agents` (`data-testid="shared-edit-badge"`)

### 423 mutations

Save / delete / mkdir use `extractLockHolder` + `formatLockHolderMessage` so
holder displayName and short session id are consistent.

### Agent runs

If run events / terminal error match lock failure text, chat/error banner shows
`formatRunLockFailureMessage` (not log-only).
