# v0.11.0 Implementation

## Summary

**M0 — Run → collab session bind (Q35).** Optional collab presence `sessionId`
on `POST /api/runs` is stored as `collabSessionId` on the run record. When
`NEOS_SHARED_EDIT=1` and `NEOS_SHARED_EDIT_AGENTS=1`, agent file PUTs can inherit
that session via `runId` / `x-neos-run-id` if they omit an explicit session.
Desktop and web pass the live collab presence id when starting project runs.

Baseline: **0.10.3**  
**Plan:** [`docs/plans/PLAN_FOR_V0_11_0.md`](../../plans/PLAN_FOR_V0_11_0.md) M0

## Wire

### Create run

```http
POST /api/runs
Content-Type: application/json
x-neos-session-id: <optional presence session>

{
  "projectId": "...",
  "prompt": "...",
  "sessionId": "<optional presence session>",
  "agentId": "cli-claude",
  "dryRun": true
}
```

- Body `sessionId` or `collabSessionId`, and/or header `x-neos-session-id`
- Invalid (control chars, length &gt; 64) → **400** `Invalid sessionId`
- Response `data.collabSessionId`: bound value or `null`

### Agent write inherit

```http
PUT /api/projects/:id/files/*
{
  "content": "...",
  "source": "agent",
  "runId": "<run with collabSessionId>"
}
# or header: x-neos-run-id: <run id>
```

Resolution order for hard-enforce session:

1. Body `sessionId` / `x-neos-session-id` (always wins)
2. If `source=agent`: look up run by `runId` / `x-neos-run-id` → use `run.collabSessionId`

Same **423** + `data.holder` shape as v0.10 when blocked.

### CLI env (spawn)

| Variable | Meaning |
|---|---|
| `NEOS_RUN_ID` | Run id (existing) |
| `NEOS_COLLAB_SESSION_ID` | Bound presence session when set (v0.11) |

## Acceptance (M0)

| Case | Expected |
|---|---|
| both flags on, run bind = holder, agent PUT with `runId` only | **200** |
| both flags on, no bind / unbound runId, agent PUT no session | **423** |
| both flags on, run bind ≠ holder | **423** |
| agents flag off, foreign bind | **200** (agent bypass) |
| illegal sessionId on create | **400** |
