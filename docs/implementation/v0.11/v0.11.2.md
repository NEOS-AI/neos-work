## Wire: tool file write

```http
POST /api/tools/files/write
Authorization: Bearer ntt_…
Content-Type: application/json
x-neos-session-id: <optional>
x-neos-run-id: <optional>

{
  "path": "index.html",
  "content": "<html>…</html>",
  "sessionId": "<optional>",
  "runId": "<optional — must match token runId if token is bound>"
}
```

### Behavior

- Capability required: **`files`** (issue via `POST …/tool-tokens` with `capabilities: ["files"]`)
- `projectId` from token only; body override → **403**
- Always `source=agent` for revisions / SSE
- When `NEOS_SHARED_EDIT=1` + `NEOS_SHARED_EDIT_AGENTS=1` and path is locked:
  - no session / bind → **423** + `data.holder`
  - holder session → **200**
  - token `runId` with run `collabSessionId` = holder → **200** without explicit session
- Agents flag off → no 423 for agent tool writes (default bypass)

### Issue token

```http
POST /api/live-artifacts/tool-tokens
{ "projectId": "…", "runId": "…", "capabilities": ["files"] }
```

- `resolveCollabSessionId` / `resolveRunIdForCollabBind`
- `resolveCollabSessionIdForWrite(..., { fallbackRunId })` — tool-token run bind

Used by `projects.ts` and `tools-files.ts`.

## CLI / MCP

When `NEOS_RUN_ID` or `NEOS_COLLAB_SESSION_ID` is set (spawned under a run):

- `neos files write` and MCP `neos_files_write` send `source: "agent"` plus session/run on PUT
- MCP throws with lock message on 423 so tools surface the failure

---

## Security

- Tool tokens remain non-Bearer daemon auth; collab `sessionId` is identity only
- `assertNoScopeOverride` prevents forging another project/run on the token
- 423 never includes host absolute paths
