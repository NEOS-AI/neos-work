# v0.7.3 Implementation

## Summary

**M3 — Canvas multi-select.** Shift+click (or ⌘/meta+click) adds or toggles
elements in a multi-selection set. Canvas overlay draws a primary frame (move +
SE resize) plus dashed secondary bboxes. Group **move** writes the same
`left`/`top` delta to every selected element’s HTML SSOT; **resize** stays
primary-only.

기준: v0.7.2

## Protocol (bridge)

| Piece | Role |
|---|---|
| Click | Replace selection (single primary outline) |
| Shift / meta+click | Toggle element in multi set |
| `selection.additive` | Flag on `neos.select` |
| `selection.multi[]` | Full ordered set after click (last = primary) |
| `neos.highlight-multi` | Parent → iframe: paint multi outlines |

Secondary outline CSS: `neos-inspect-sel-multi` (dashed indigo).

---

## Canvas overlay

| Prop | Role |
|---|---|
| `bbox` | Primary frame (handles) |
| `extraBboxes` | Secondary dashed frames |
| Move gesture | Nudges all frames live; parent applies multi HTML delta |
| SE resize | Primary only |

Label: `N selected · Move` when multi.

## Limits

- Resize is primary-only (no group scale).  
- Multi set is session-local (not collab-broadcast as multi; collab M2 still sends primary selector).  
- JSX layers: multi via Layers Shift+click; canvas bbox needs HTML bridge bbox.
