## Usage

Same flag as v0.6.2 canvas:

```bash
VITE_NEOS_CANVAS_OVERLAY=1 pnpm --filter @neos-work/web dev
```

1. Inspect-select an element (bbox required)  
2. Drag frame to **move**  
3. Drag **SE corner** to **resize** → `width`/`height` on the element style
