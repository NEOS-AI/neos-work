## Layout

```text
apps/desktop/src/lib/
  engine-transport.ts   # SSE/HTTP helpers + EngineTransport base
  engine-project.ts     # Design Project types + collab/files/runs API
  engine.ts             # EngineClient + other domains; re-exports all
```

| Class | Role |
|---|---|
| `EngineTransport` | `baseUrl`, auth, headers, path segments, invalid id |
| `EngineProjectClient` | projects, files, collab, revisions, comments, runs |
| `EngineClient` | sessions, workflows, media, workers, … |

Call sites keep `import { EngineClient, DesignProject } from '../lib/engine.js'`.
