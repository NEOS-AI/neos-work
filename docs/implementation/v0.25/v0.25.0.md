# v0.25.0 Implementation — Track A Web ops surface

## Summary

Ship thin **browser ops** pages that already had REST on the daemon:

- Sessions + workspaces + chat SSE
- Memory CRUD / toggle
- Plugins list + marketplace catalog fetch (optional install)
- Workers list (read-only)
- Domain packs list (read-only)

Not a clone of every desktop panel (agent step virtuoso, pack zip install, plugin run SSE).

## Routes

| Path | Page |
|---|---|
| `/sessions` | Chat sessions + workspace picker |
| `/memory` | Memory list + create/edit/toggle/delete |
| `/plugins` | Installed plugins + catalog |
| `/workers` | Domain workers list |
| `/domain-packs` | Packs list |

## API client

`WebApiClient` methods: `listSessions`, `createSession`, `deleteSession`, `listSessionMessages`, `streamSessionChat`, `cancelSession`, `confirmSessionTool`, `listWorkspaces`, `createWorkspace`, `deleteWorkspace`, `listMemories`, `createMemory`, `updateMemory`, `deleteMemory`, `toggleMemory`, `listPlugins`, `fetchMarketplaceCatalog`, `installMarketplaceEntry`, `listWorkers`, `listDomainPacks`.

## Dual-surface

`docs/reference/dual-surface.md`: Sessions, Memory, Plugins catalog, Workers, Domain packs = **yes (v0.25)** (thin).
