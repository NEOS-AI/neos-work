# v0.3.92 Implementation

## Summary

PLAN_FOR_V0_3_0 residual polish: **routine concurrent run lock** (Task 2),
**routine name/inputs/error caps**, **session title/model hygiene**, **browser
tool size caps**, **memory create error mapping**, **deploy content 2 MiB
align + deployment field caps**, **harness name/tools/constraints hygiene**,
**revision label hygiene**, **MCP name/command/args hygiene**, **filesystem
read/list/search bounds**, and **executor node error truncate**.

기준: v0.3.91

## Changes

### Task 1: Routine scheduler (Task 2)

- In-memory `runningRoutines` lock skips overlapping schedule/manual triggers
- Lock always released in `finally`
- Exported `isRoutineRunning` for tests

### Task 2: Routines DB

- Name: reject control chars; max 200 chars
- Inputs JSON max 256 KiB (create throw / update null)
- Complete-run error messages capped at 4_000 chars

### Task 3: Sessions / harnesses

- Session title truncated at 200 chars (create/update)
- Invalid/control-char model id falls back to default Claude model
- Harness name: control-char reject; max 200
- Allowed tools: drop control-char/overlong names; max 100 tools
- Constraints JSON max 16 KiB

### Task 4: Browser tools

- Selector: reject control chars; max 1_000
- Fill value max 100 KiB
- Extracted text truncated at 500 KiB
- Links capped at 500
- Screenshot max 8 MiB raw bytes

### Task 5: Memory / deploy / revisions / MCP

- Memory POST maps createMemory validation errors to 400
- Deploy content limit aligned to 2 MiB (matches deploy lib)
- Deployment projectName ≤ 63; deploymentId ≤ 200; statusMessage ≤ 4k
- Revision labels: reject control chars; max 200
- MCP name/command control-char reject; command ≤ 500; args ≤ 50×500

### Task 6: Filesystem tools / executor

- `read_file` truncates at 1 MiB with marker
- `list_directory` caps entries at 1_000
- `search_files` rejects control-char / overlong patterns
- Executor truncates `node.failed` errors at 4_000 chars

### Task 7: Unit tests

- Routine name/inputs rejection
- Scheduler concurrent skip
- Session title/model hygiene
- Browser fill/extract caps
- Harness name/tools hygiene
- Deployment field caps; revision label hygiene
- MCP control-char name/command
- Filesystem read truncate + search pattern reject

### Task 8: Version

- monorepo **0.3.91 → 0.3.92**
- health / server banner / web_search User-Agent / MCP client version
