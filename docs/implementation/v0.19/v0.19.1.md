# v0.19.1 Implementation

## Summary

**Track B — Shared run event fan-out MVP.** Extend the v0.16 shared run store
with a capped per-run event buffer so multi-replica engines can serve
`GET /api/runs/:id/events` and `GET /api/runs/:id/events/stream` when the live
run is owned by another process. Owner still dual-writes summaries; events are
appended best-effort into the same `NEOS_RUN_REGISTRY` backend.

**Not** a durable event log / not Postgres. Cap ~500 events, TTL aligned with
summary (~3600s). Poll-based SSE (250ms / 10min) is enough; sticky SSE not
required for this path.

Baseline: monorepo with v0.16 shared summary store  
**Ops:** [`docs/ops/multi-replica-collab.md`](../../ops/multi-replica-collab.md) ·
[`docs/ops/sticky-sse.md`](../../ops/sticky-sse.md)

Same as v0.16 run registry — **no new env vars**.

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_RUN_REGISTRY` | `auto` | Summary **and** event buffer mode |
| `NEOS_COLLAB_REDIS_URL` / `REDIS_URL` | unset | Redis URL for redis path |

When `NEOS_RUN_REGISTRY=off`: no dual-write; remote events still 404.

## API surface (`run-registry-shared.ts`)

```ts
// SharedRunStore additions
appendEvent(runId: string, event: RuntimeRunEvent): Promise<void>
eventsAfter(runId: string, afterEventId?: string): Promise<RuntimeRunEvent[]>
onRunEvent(handler: (runId, event) => void): () => void

// Helpers
dualWriteRunEvent(runId, event): Promise<void>
appendRunEvent(reg, id, type, data?): RuntimeRunEvent | undefined
```

Constants: `RUN_EVENT_BUFFER_MAX = 500`, `RUN_SUMMARY_TTL_SEC = 3600`.

## Redis keys (additions)

| Key / channel | Type | Role |
|---|---|---|
| `neos:run:events:{id}` | LIST JSON | RPUSH + LTRIM last N + EXPIRE |
| `neos:run:eventbus` | pub/sub | `{ runId, event }` live notify (SSE still polls) |

## Behaviour

| Path | Behaviour |
|---|---|
| Owner `appendRunEvent` | Local `reg.appendEvent` then best-effort `dualWriteRunEvent` |
| `GET /:id/events` | Local first; else if shared summary exists → `eventsAfter`; else 404 |
| `GET /:id/events/stream` | Local path unchanged; remote path SSE-polls shared buffer + re-fetches summary each loop; ends when terminal and drained |
| Cancel (local) | Dual-write summary + last `run.canceled` event |
| `off` mode | No event dual-write; remote events 404 |
