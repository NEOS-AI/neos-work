## Changes

### Task 1: Design systems (Task 1)

- Cap DESIGN.md updates at 1 MiB (`DESIGN_MD_MAX_CHARS`)
- Cap description at 2_000 chars on create
- Route rejects oversized content with 400

### Task 2: AgentNode (Task 14)

- Cap injected design context at 32 KiB with truncation marker

### Task 3: Settings / messages

- `setSetting`: reject control-char keys, keys > 200 chars, values > 1 MiB
- Route uses shared max constant + try/catch
- `addMessage`: content ≤ 1 MiB; metadata JSON > 64 KiB → truncated marker

### Task 4: Artifacts / media / coding / plugin / Slack

- Artifact name: reject `\0`/CR/LF and length > 500
- TTS audio: cap binary size at 16 MiB
- Coding `runSpawn`: cap combined stdout/stderr at 512 KiB
- Plugin stages: safe placeholder keys; prompt ≤ 100k; output ≤ 200k
- Slack channel: reject control characters

### Task 5: MCP OAuth / HTML / session

- Invalid `expiresAt` treated as expired (fail closed)
- HTML artifact detection scans only first 8 KiB for markers
- Session memory tool tags: safe JSON array parse

### Task 6: Unit tests

- Design system oversized content
- Agent design-context truncate
- Settings key/value rejection
- Artifact name control-chars
- Slack channel control-chars
- Blocks normalizeImplementationType unit
- Cron timezone blank reject (coverage)
