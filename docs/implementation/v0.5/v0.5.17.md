### Environment

| Variable | Role |
|---|---|
| `NEOS_SERVER_URL` / `NEOS_URL` | Daemon base URL |
| `NEOS_AUTH_TOKEN` / `NEOS_TOKEN` | Bearer (from daemon stdout) |
| `NEOS_PORT` | Default port when URL unset |
| `NEOS_PROJECT_ID` | Default design project |
| `NEOS_PROJECT_DIR` | Optional cwd hint |
| `NEOS_CLI_TIMEOUT_MS` | Request timeout |

### Exit codes

| Code | Meaning |
|---|---|
| 0 | ok |
| 2 | usage |
| 10 | daemon down |
| 11 | unauthorized |
| 12 | not found |
| 13 | capability denied |
| 14 | validation |
| 15 | network |
| 1 | internal |

### Commands (this release)

```text
neos version
neos status [--json]
neos doctor [--json]
neos daemon status
neos project list|create|get
neos files ls|read|write --project <id>
neos run create|status|cancel   # --edit-context JSON supported
neos media list
neos plugin list
neos deploy list [--project|--workflow]
neos env [--json]               # shell exports for agents
```

`daemon start|stop` prints guidance (desktop Host Mode / `pnpm --filter @neos-work/server dev`).

## Usage

```bash
# after server start, copy token from stdout:
export NEOS_AUTH_TOKEN=…
export NEOS_SERVER_URL=http://127.0.0.1:3000

pnpm --filter @neos-work/cli build
pnpm --filter @neos-work/cli exec neos status --json
# or
pnpm cli -- status
```
