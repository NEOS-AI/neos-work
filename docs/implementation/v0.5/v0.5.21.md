# v0.5.21 Implementation

## Summary

**PLAN_FOR_V0_5_0 Task 12 foundation (Web client + static serve).** Adds
`apps/web` — a Vite + React browser client with token UX, projects list, and
simple file open/save against the daemon. Server can optionally serve
`apps/web/dist` via `NEOS_WEB_DIST` (or auto-detect monorepo dist).

기준: v0.5.20  
참고: Full `packages/ui-app` extraction deferred; this is a thin dual-surface
client, not a full desktop page port.

## apps/web

| Route | Role |
|---|---|
| `/` | Connect: server URL + Bearer token |
| `/projects` | List design projects |
| `/projects/:id` | File list + read/write editor |

Dev: Vite port **5173**, proxies `/api` → `NEOS_SERVER_URL` or `127.0.0.1:3000`.

Env storage keys: `neos.web.serverUrl`, `neos.web.authToken` (opt-in remember).

## Server

| Piece | Notes |
|---|---|
| `GET /api` | Engine banner JSON (version) |
| `GET /` | SPA or JSON banner if no web dist |
| `resolveWebDist()` | `lib/web-static.ts` |
| Static | `@hono/node-server/serve-static` + SPA fallback |

```bash
pnpm --filter @neos-work/web build
NEOS_WEB_DIST=$PWD/apps/web/dist pnpm --filter @neos-work/server start
```
