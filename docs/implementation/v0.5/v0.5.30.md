## Hash-aware disk reload

`@neos-work/design-editor`:

- `shouldSkipDiskReload(state, { path, hash })` — true when event hash matches
  known `diskHash` or `pendingDiskHash`
- `disk-changed` reducer ignores matching `diskHash` without content thrash

**Web** `ProjectDetail` and **desktop** `ProjectWorkspace` SSE handlers skip
`readFile` when the event hash already matches the open buffer tip.
