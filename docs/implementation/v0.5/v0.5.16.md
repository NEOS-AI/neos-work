# v0.5.16 Implementation

## Summary

**PLAN_FOR_V0_5_0 Task 10 (M4 Deploy polish).** Adds **check-link** reachability
for deployment URLs (private/loopback blocked), **richer preflight** (token
format / placeholder warnings, severity), **project-scoped deployment history**
(`project_id` + list filter), and **secret mask audit** on preflight messages,
status refresh, and deploy errors.

기준: v0.5.15  
참고: Vercel/Cloudflare deploy + history pre-existed; this hardens OD §19 parity.

| POST | `/api/deploy` | optional `projectId` (must exist) |

### check-link result

```ts
{ url, reachable, blocked, ok, status?, reason?, contentType? }
```

Blocked: localhost, 127/10/192.168/172.16–31, link-local, `.local`.

### Preflight

- Missing credentials → `severity: error` → `ready: false`
- Placeholder tokens (`changeme`, `xxx`, short) → `severity: warn` (does not block ready if present)
- Project name validation unchanged
