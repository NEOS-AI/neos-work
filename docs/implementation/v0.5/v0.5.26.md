## Desktop Settings — NEOS as MCP server

- Loads `GET /api/mcp/install-info` (+ optional token hide)
- Shows tool chips, shell snippet, Claude Desktop JSON, Codex CLI line
- Copy buttons; Codex status + Install / Remove
- EngineClient: `getMcpInstallInfo`, `listNeosMcpTools`, `getCodexMcpInstallStatus`,
  `installCodexMcp`, `uninstallCodexMcp`

---

## Web run → file reload

1. `POST /api/runs` with `editContext`
2. Poll `GET /api/runs/:id` until terminal status (≤ ~30s)
3. Re-read open file → `reduceEditorBuffer({ type: 'disk-changed' })`
   - clean buffer: accept agent tip
   - dirty buffer: DesignEditor conflict banner (Keep / Take / Diff)
