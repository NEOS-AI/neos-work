## SSRF module (`apps/server/src/lib/ssrf.ts`)

| Export | Role |
|---|---|
| `isBlockedSsrfHost` | Private/loopback/metadata hostnames |
| `parseHttpUrl` | http(s) only; optional private allow |
| `assertDnsPublic` | Reject DNS A/AAAA in private ranges |
| `assertSafeOutboundUrl` | Full outbound guard |
| `isSafeHttpUrlScheme` | Config-safe URL (private OK for Ollama) |

Deploy re-exports `isBlockedDeployCheckHost` as alias of `isBlockedSsrfHost`.

## API

### `POST /api/connection-test`

```json
{ "target": "openai" | "anthropic" | "ollama" | "url" | "cli-agents", "url?": "…" }
```

Response (never secrets / body content):

```json
{ "ok": true, "data": { "target", "reachable", "blocked?", "status?", "message?", "catalogCount?" } }
```

- Private hosts for `target=url` → `blocked: true`  
- Ollama allows loopback intentionally  
- `cli-agents` = catalog count only (no network)

Desktop: `EngineClient.connectionTest(...)`.
