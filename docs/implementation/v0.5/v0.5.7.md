# v0.5.7 Implementation

## Summary

**PLAN_FOR_V0_5_0 Task 4 foundation — Skill package protocol.** Extends skill
discovery beyond flat `*.md` to OD-style packages (`dir/SKILL.md` +
assets/references/examples), implements name **shadowing** (local → global →
bundled), derives example cards from `examples/*.html`, ships **≥5 bundled**
skills under repo `skills/`, and surfaces package metadata in the Skills API/UI.

기준: v0.5.6  
참고: Existing frontmatter parser retained; scan path gains package roots.
