# v0.5.25 Implementation

## Summary

**PLAN_FOR_V0_5_0 Task 12 remainder (Web Design Editor).** Wires the browser
client (`apps/web`) to the shared **`@neos-work/design-editor`** package so web
and desktop share Preview · Code · Layers · Inspect. Project detail becomes a
full Design Editor workspace with dirty `beforeunload` guard and selection-
scoped **Edit with AI** runs (`editContext`, Q10 patch-first).

`packages/ui-app` page extraction remains deferred — editor is shared via the
design-editor package instead.

## Web workspace layout

```text
Files | DesignEditor (Layers · Preview/Code/Split/Inspect) | Edit with AI
```

- Buffer state: `createEmptyBuffer` / `reduceEditorBuffer` / `isDirty`
- Save: `PUT /api/projects/:id/files/*` with `source: user`
- AI: `editContextFromSelection` → `mode: replace-selection` by default
