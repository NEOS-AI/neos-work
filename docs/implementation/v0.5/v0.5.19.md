## Server env (Docker-oriented)

| Variable | Effect |
|---|---|
| `NEOS_HOST` | Bind address (default `127.0.0.1`; image uses `0.0.0.0`) |
| `NEOS_PORT` / `PORT` | Listen port |
| `NEOS_DATA_DIR` | SQLite + media root (`/data` in compose) |
| `NEOS_AUTH_TOKEN` | Stable bearer (min 16 chars); else random each process |
| `NEOS_ALLOW_ANY_HOST` | Skip Host header allowlist (`1` in image) |
| `NEOS_ALLOWED_HOSTS` | Extra Host allowlist entries |
| `NEOS_CORS_ORIGINS` | Extra browser CORS origins |

`resolveDbDir()` / `resolveMediaDir()` respect `NEOS_DATA_DIR`.
