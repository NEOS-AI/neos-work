## Manifest (`pack.json` / `neos-pack.json`)

```json
{
  "schema": "neos-domain-pack/v1",
  "id": "legal",
  "name": "Legal",
  "description": "…",
  "version": "1.0.0",
  "icon": "scale",
  "workers": [
    {
      "id": "legal_reviewer",
      "name": "Legal Reviewer",
      "systemPrompt": "…",
      "permissionProfile": "read_only",
      "allowedTools": ["read_file"]
    }
  ],
  "blocks": [
    {
      "id": "legal_clause_check",
      "name": "Clause Check",
      "implementationType": "prompt",
      "promptTemplate": "Review: {{input}}"
    }
  ]
}
```

**Rejects:** wrong schema, reserved built-in ids, empty workers+blocks, `native`
blocks, unsafe ids, invalid JSON.

## workflow-engine

| Export | Role |
|---|---|
| `parsePackManifest` | Validate raw JSON/object |
| `registerPack` / `registerPackFromManifest` | Runtime register |
| `unregisterPack` | Remove custom pack + owned workers/blocks |
| `setPackEnabled` | Disable (drop runtime) / re-enable |
| `listPacks` / `resolvePack` | Built-in **and** custom |
| `unregisterBlockMeta` | Block registry cleanup |

Custom pack workers use **pack id as domain** (not forced to `general`).
Block domain normalization accepts safe custom slugs.

## Server store & API

**Store:** `$NEOS_DATA_DIR/domain-packs/<id>/pack.json` + `state.json`  
Boot: `loadInstalledDomainPacks()` hydrates the runtime registry.

| Method | Path | Role |
|---|---|---|
| GET | `/api/domain-packs` | List (built-in + custom, enabled, counts) |
| GET | `/api/domain-packs/:id` | Detail + workers + blocks |
| POST | `/api/domain-packs/validate` | Dry-run manifest parse |
| POST | `/api/domain-packs/install` | `{ "path": "/local/dir" }` |
| POST | `/api/domain-packs/install-zip` | Raw ZIP or multipart |
| POST | `/api/domain-packs/:id/toggle` | `{ "enabled": boolean }` |
| DELETE | `/api/domain-packs/:id` | Uninstall custom only |

ZIP install: root (or single-folder) `pack.json`; shallow `.json`/`.md`/`.txt` only;
path traversal rejected; max 10 MB / 100 files.
