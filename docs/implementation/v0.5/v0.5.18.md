## New / updated commands

```text
neos skills list|scan
neos design-systems list
neos memory list|add --name … --type … --content …
neos mcp list
neos media list|config|generate --surface image|audio|video --prompt …
neos plugin list|atoms
neos daemon start [--port N] [--entry path]
neos daemon stop
neos daemon status
```

### daemon start flow

1. If health already ok → report already running  
2. Spawn `@neos-work/server` entry (`dist/index.js` or `src/index.ts` via tsx)  
3. Parse stdout for `NEOS_PORT=` / `NEOS_AUTH_TOKEN=`  
4. Write `~/.neos-work/cli-daemon.json` (mode 0600)  
5. Print `export NEOS_SERVER_URL=…` and `export NEOS_AUTH_TOKEN=…`  
6. `child.unref()` so CLI can exit while daemon keeps running  

`daemon stop` reads the session file and `SIGTERM`s the pid.
