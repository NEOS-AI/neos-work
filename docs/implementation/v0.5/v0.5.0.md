## Changes

### Shared (`@neos-work/shared`)

- New `types/project.ts`: `DesignProject`, `ProjectFileEntry`, `FileRevision`,
  `PreviewComment`, `EditContext` (+ `normalizeEditContext`, Q10 default
  `replace-selection`), `ProjectRun`, `LiveArtifact`, `PluginSnapshot`,
  `LayerNode`, `SelectionState`
- Barrel export + unit tests

### Server

- Schema additive tables for Design Projects
- `path-sandbox`: relative path normalize, `resolveUnderRoot`, import `baseDir`
  validation, default `~/.config/neos-work/projects`
- `project-files`: recursive list (skip hidden/symlinks), read/write with size
  caps, entry detection (`index.html`, …)
- `db/projects.ts`: CRUD, revisions (cap 50), preview comments, conversations
- `GET/POST/PUT/DELETE /api/projects…` including files splat, revisions restore
- Seed `index.html` on empty default workspace
- Health / root banner **0.5.0**

### Fixture

- `e2e/fixtures/od-samples/index.html` — Layers/Inspect sample markup

### Version

- monorepo + packages **0.4.4 → 0.5.0**
- web_search User-Agent, MCP client version

## API surface (M1)

| Method | Path | Notes |
|---|---|---|
| GET/POST | `/api/projects` | list / create (`baseDir` optional import) |
| GET/PUT/DELETE | `/api/projects/:id` | meta + working-dir update |
| GET | `/api/projects/:id/files` | recursive listing |
| GET/PUT/DELETE | `/api/projects/:id/files/*` | read / write (+ revision) / delete |
| POST | `/api/projects/:id/mkdir` | `{ path }` |
| GET | `/api/projects/:id/revisions?path=` | list (no content) |
| GET | `/api/projects/:id/revisions/:revisionId` | full content |
| POST | `/api/projects/:id/revisions/:revisionId/restore` | write tip from revision |
| GET/POST | `/api/projects/:id/preview-comments` | |
| DELETE | `/api/projects/:id/preview-comments/:commentId` | |
| GET/POST | `/api/projects/:id/conversations` | chat shell |
| GET/POST | `…/conversations/:cid/messages` | |
