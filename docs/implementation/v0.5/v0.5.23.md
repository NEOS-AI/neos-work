## MCP tools (`neos mcp serve`)

stdio MCP server (stdout = JSON-RPC only; logs on stderr). Proxies to the
local daemon with `NEOS_SERVER_URL` + `NEOS_AUTH_TOKEN`.

| Tool | Role |
|---|---|
| `neos_status` | Daemon health + tool list |
| `neos_projects_list` | Design projects |
| `neos_files_list` | Project file tree |
| `neos_files_read` | Read text file (path sandbox) |
| `neos_files_write` | Write text file |
| `neos_live_artifacts_list` | List live artifacts |
| `neos_live_artifacts_create` | Create live artifact |
| `neos_live_artifacts_refresh` | Refresh artifact |

`projectId` may be omitted when `NEOS_PROJECT_ID` is set.

## APIs

| Method | Path | Role |
|---|---|---|
| GET | `/api/mcp/install-info` | Claude Desktop fragment, Codex CLI, shell snippet |
| GET | `/api/mcp/tools` | Tool catalog |
| GET | `/api/mcp/install/codex/status` | Codex CLI present? `neos-work` registered? |
| POST | `/api/mcp/install/codex` | `codex mcp add neos-work …` |
| DELETE | `/api/mcp/install/codex` | `codex mcp remove neos-work` |

Query: `projectId`, `neosBin`, `includeToken=0` (omit secrets from response).

Daemon never edits `~/.codex/config.toml` directly — always shells out to
`codex mcp …`.
