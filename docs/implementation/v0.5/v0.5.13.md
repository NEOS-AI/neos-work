## Import token flow

```text
[Browse / type path]
        │
        ▼
POST /api/projects/import-token  { path }
        │
        ▼  { token, path, expiresAt }
POST /api/projects  { name, baseDir, importToken }
        │
        ▼  token consumed (single-use)
   DesignProject row (baseDir = realpath)
```

- TTL default **5 minutes**
- Token store is in-process memory (daemon restart clears pending tokens)
- Bogus / reused token → **403**
- Missing token + baseDir → still allowed (server/API compat); desktop always sends token

## API

| Method | Path | Notes |
|---|---|---|
| POST | `/api/projects/import-token` | body `{ path }` → token + canonical path |
| POST | `/api/projects` | optional `importToken` when `baseDir` set |
| PUT | `/api/projects/:id` | optional `importToken` when changing `baseDir` |
| GET | `/api/plugins` | existing `meta.channels` + per-plugin `channel` |
