# v0.5.4 Implementation

## Summary

**PLAN_FOR_V0_5_0 Task 1c (E3) — Design Editor Inspect + Layers tree.** Extends
`@neos-work/design-editor` with sandbox-safe iframe bridge inject, HTML parse
fallback layers, Figma-like Layers panel (filter, select, visibility/lock),
Inspect mode + selection detail strip, unified `SelectionState`, and
Edit-with-AI hooks wired into Project workspace chat `editContext`.

기준: v0.5.3  
참고: `PLAN_FOR_V0_5_0` Task 1c; residual chat/runs live CLI already on 0.5.3.
