## Capability inventory

```bash
pnpm inventory           # stdout JSON
pnpm inventory:write     # docs/generated/capability-inventory.json
pnpm inventory:check     # exit 1 if gates fail
pnpm test:inventory      # node:test unit tests
```

**Gates (minima):**

| Catalog | Min | Typical |
|---|---|---|
| Agent CLI defs | 12 | 13 |
| Plugin atoms | 12 | 15 |
| Skills | 5 | 5 |
| Design systems | 2 | 2 |
| Media providers | 4 | 6 |
| Media surfaces | 3 | 3 |
| MCP tools | 6 | 8 |
| Domain packs | 4 | 4 |

Scans source/catalog files under the monorepo (no live daemon required).
