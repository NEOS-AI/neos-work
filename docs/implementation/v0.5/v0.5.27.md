## Server

### Hub — `lib/project-file-events.ts`
- In-process pub/sub per `projectId`
- Events: `file.changed` · `file.created` · `file.deleted`
- Payload: `{ type, projectId, path, source?, hash?, ts }`
- Caps listeners per project; safe against bad path/`projectId`

### Route — `GET /api/projects/:id/events/stream`
- `text/event-stream` with `ready` handshake + 1s heartbeats
- Max lifetime 30m; cleans up on abort

### Publishers
| Path | Event |
|---|---|
| `PUT .../files/*` | `file.created` or `file.changed` (+ hash, source) |
| `DELETE .../files/*` | `file.deleted` |
| revision restore | `file.changed` (source `restore`) |
| CLI run exit | `file.created` / `file.changed` via size+mtime snapshot |

---

## Clients

### Web (`ProjectDetail`)
- `WebApiClient.streamProjectFileEvents` (fetch + Bearer)
- While a file is open, matching `file.changed` / `file.created` → re-read →
  `reduceEditorBuffer({ type: 'disk-changed' })` (conflict banner if dirty)
- Run poll kept for status UX; SSE is primary for live disk updates

### Desktop
- `EngineClient.streamProjectFileEvents` mirrors web SSE client
