## Live smoke

```bash
# Default: skip exit 0 (safe for CI)
pnpm e2e:live-smoke

# Opt-in public probes (no keys; 401/403 = reachable)
NEOS_LIVE_SMOKE=1 pnpm e2e:live-smoke

# Optional daemon connection-test
NEOS_LIVE_SMOKE=1 \
  NEOS_SERVER_URL=http://127.0.0.1:3000 \
  NEOS_AUTH_TOKEN=… \
  pnpm e2e:live-smoke
```

Script: `e2e/live-smoke/run.mjs`  
- Never logs HTTP response bodies  
- Inventory gates + OpenAI/Anthropic reachability  
- Ollama only if `NEOS_LIVE_SMOKE_OLLAMA=1`
