## Changes

### Task 1: Engine client HTTP errors

- `formatHttpErrorMessage(status, statusText)` — strip null bytes, collapse
  CR/LF, cap length; used by chat / runAgent non-OK responses
- `scrubApiErrorMessage` — same for webhook fire API/statusText errors
- Exported for unit tests

### Task 2: Workflow draft serialization

- `buildWorkflowDraft`: control-char node labels fall back to id; control
  nodeType → `trigger` default; edge labels length-capped
- `toReactFlowNodes` / `toReactFlowEdges`: same hygiene when loading persisted
  graphs (import / restore path)

### Task 3: Sessions screenshots

- `safeScreenshotBase64`: reject control chars, non-base64 alphabet, overlong
  payloads; strip accidental data-URL prefix
- Applied when completing agent steps and when rendering `ScreenshotToggle`
  (invalid → no toggle)

### Task 4: Unit tests

- formatHttpErrorMessage / scrubApiErrorMessage control cases
- chat / runAgent control statusText → scrubbed error chunks
- workflow-draft control labels/types (build + toReactFlow)
- Sessions hides screenshot toggle for control-char base64

- health / server banner / web_search User-Agent / MCP client version
