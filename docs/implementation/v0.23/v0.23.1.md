# v0.23.1 Implementation — Track W: Web Media generate UI

## Summary

Expand the web client beyond the Design Project loop with a thin **Media** page
(list + generate), matching dual-surface policy: web stays intentionally thin
but gains media UI that was previously desktop-only.

## Scope

| Area | Change |
|---|---|
| `WebApiClient` | `listMediaFiles`, `listMediaProviders`, `generateMedia`, `getMediaJob`, `mediaFileUrl`, `fetchMediaBlob` |
| Page | `apps/web/src/pages/Media.tsx` — auth gate, list, generate form, scrubbed errors |
| Routing | `/media` in `App.tsx` |
| Nav | Projects + Settings → Media |
| Settings | `OPENAI_API_KEY` row (save only; no verify-key provider yet) |
| Docs | `dual-surface.md` Media generate UI web = **yes** (v0.23) |
