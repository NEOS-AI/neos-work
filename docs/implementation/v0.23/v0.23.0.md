# v0.23.0 Implementation — Track K: encryption master key resolution

## Summary

**Track K — pluggable master key for AES-encrypted settings.** Sensitive values
remain AES-256-GCM in SQLite (`apps/server/src/db/crypto.ts`), but the master
key is no longer only machine-derived (`hostname:homedir:neos-work-v1`).

Operators can supply `NEOS_MASTER_KEY`, use a **file keychain** under the data
dir, or keep legacy machine-derived keys for back-compat.

Native OS keyring (keytar / secret-service) is **not** required for MVP; the
file keychain is the documented “keychain path.” OS keyring can plug into the
same `Keychain` interface later.

## Key resolution order

`NEOS_SECRETS_KEY_BACKEND` (default `auto`):

| Backend | Behavior |
|---|---|
| `auto` | `NEOS_MASTER_KEY` → existing file/keychain key → **legacy** (no auto-create; preserves installs) |
| `env` | Require `NEOS_MASTER_KEY` (fail if missing) |
| `file` | File keychain under data dir; **auto-create** random 32-byte key if missing |
| `legacy` | Force machine-derived key |

Sources logged as `NEOS_SECRETS_KEY_SOURCE=env|keychain|file|legacy` (no secret material).

### `NEOS_MASTER_KEY` formats

1. **64 hex chars** → 32 raw bytes  
2. **Base64** decoding to exactly 32 bytes  
3. **Any other string** → SHA-256 (32 bytes)

## Env

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_MASTER_KEY` | (unset) | Operator master key material |
| `NEOS_SECRETS_KEY_BACKEND` | `auto` | `auto` \| `env` \| `file` \| `legacy` |
| `NEOS_DATA_DIR` | `~/.neos-work` | Data root; file key lives at `{dir}/.secrets/master.key` (mode `0600`) |

Startup log: `NEOS_SECRETS_KEY_SOURCE=…` (source only).

## File keychain

Path: `{NEOS_DATA_DIR}/.secrets/master.key`  

Stores **only** a random 32-byte AES key (not API tokens). Permissions best-effort `0600` on the file and `0700` on `.secrets/`.
