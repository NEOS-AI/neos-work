# v0.23.2 Implementation — Track P Postgres run warehouse

## Summary

Optional **Postgres** backend for long-lived run summary + events, complementing
the Redis buffer (`NEOS_RUN_REGISTRY`) and durable JSONL (`NEOS_RUN_EVENT_LOG`).
Default remains **off** — no Postgres required for local/CI.

Not a replacement for the SQLite app DB.

## Env

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_RUN_WAREHOUSE` | `off` | `off` \| `postgres` (`pg` / `on` aliases → postgres) |
| `NEOS_RUN_WAREHOUSE_URL` | unset | Preferred connection string |
| `DATABASE_URL` | unset | Fallback connection string |
| `NEOS_RUN_WAREHOUSE_SCHEMA` | `public` | Schema for tables (e.g. `neos`) |

## Behaviour

When `NEOS_RUN_WAREHOUSE=postgres` and a URL is set:

1. **Dual-write summary** (`dualWriteRunRecord` / `syncRunSummary`) → UPSERT `neos_run_summary`
2. **Dual-write event** (`dualWriteRunEvent`) → INSERT `neos_run_event` (append-only, PK dedupe)
3. **GET `/api/runs/:id`** after local + shared + durable JSONL miss → warehouse `getSummary`
4. **GET `/api/runs/:id/events`** when buffer + JSONL empty → warehouse `listEventsAfter`

If URL is missing, `pg` is unavailable, or connect fails → status kind `postgres-stub`
(no-ops; process still starts).

## Schema (auto-migrate on connect)

```sql
CREATE SCHEMA IF NOT EXISTS "<schema>";  -- default public

CREATE TABLE IF NOT EXISTS <schema>.neos_run_summary (
  id TEXT PRIMARY KEY,
  status TEXT NOT NULL,
  node_id TEXT NOT NULL,
  project_id TEXT,
  collab_session_id TEXT,
  agent_id TEXT,
  error TEXT,
  created_at TIMESTAMPTZ NOT NULL,
  started_at TIMESTAMPTZ,
  completed_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ NOT NULL,
  payload JSONB
);

CREATE TABLE IF NOT EXISTS <schema>.neos_run_event (
  run_id TEXT NOT NULL,
  event_id TEXT NOT NULL,
  type TEXT NOT NULL,
  ts TIMESTAMPTZ NOT NULL,
  data JSONB,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  PRIMARY KEY (run_id, event_id)
);

CREATE INDEX IF NOT EXISTS neos_run_event_run_ts
  ON <schema>.neos_run_event (run_id, ts);
```

## Startup log

```text
NEOS_RUN_WAREHOUSE=off
NEOS_RUN_WAREHOUSE=postgres schema=public
NEOS_RUN_WAREHOUSE=postgres-stub (…URL unset…)
```

## Operator example

```bash
NEOS_RUN_WAREHOUSE=postgres \
NEOS_RUN_WAREHOUSE_URL=postgres://neos:neos@db:5432/neos \
NEOS_RUN_WAREHOUSE_SCHEMA=neos
```

## Constraints

- Default **off** — existing tests green without Postgres
- JSONL path unchanged and not removed
- Monorepo version not bumped for this track alone
- Web app untouched
