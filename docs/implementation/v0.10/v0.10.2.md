## Breaking change

| Old | Status | Replacement |
|---|---|---|
| `GET/POST /api/harness` | **410** | `/api/workers` |
| `GET/PUT/DELETE /api/harness/:id` | **410** | `/api/workers/:id` |
| Same under `/api/harnesses` | **410** | same |

Response shape:

```http
HTTP/1.1 410 Gone
Deprecation: true
Link: </api/workers>; rel="successor-version"
X-Neos-Deprecated: Use /api/workers - harness HTTP aliases removed in 0.10.2

{
  "ok": false,
  "error": "Gone: /api/harness and /api/harnesses were removed in 0.10.2. Use /api/workers instead.",
  "data": { "successor": "/api/workers", "removedIn": "0.10.2" }
}
```

**Not removed:** workflow-engine `listHarnesses` / `registerHarness` in-process APIs;
SQLite `workers` table; desktop UI route `/harnesses` (workers page URL stability).
