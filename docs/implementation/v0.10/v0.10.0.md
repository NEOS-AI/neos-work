## Env

| Variable | Default | Meaning |
|---|---|---|
| `NEOS_SHARED_EDIT` | off | Base hard-enforce for **user** mutations |
| `NEOS_SHARED_EDIT_AGENTS` | off | Also hard-enforce **agent** PUTs (requires base on) |

```bash
NEOS_SHARED_EDIT=1 \
NEOS_SHARED_EDIT_AGENTS=1 \
  pnpm --filter @neos-work/server dev
```

---

## Behavior

| Flags | User PUT on locked path | Agent PUT on locked path |
|---|---|---|
| both off | allowed (advisory) | allowed |
| SHARED only | 423 unless holder | **allowed** (bypass) |
| both on | 423 unless holder | **423** unless holder session |

Agent as holder: send `sessionId` body and/or `x-neos-session-id` matching the lock.
