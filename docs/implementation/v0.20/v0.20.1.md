# v0.20.1 Implementation — Track D project client split

## Summary

**Track D — Split Design Project engine client.** Breaks the ~1.3k-line
`engine-project.ts` into Core / Collab / Files / leaf without renaming
`EngineProjectClient` (required by `EngineWorkflowClient extends …`).

---

## Hierarchy

```text
EngineTransport
  → EngineProjectCoreClient      // CRUD, zip, projectRelPathSegments, types
    → EngineProjectCollabClient  // collab + file events stream
      → EngineProjectFilesClient // files, revisions, comments
        → EngineProjectClient    // conversations + project runs (LEAF)
```

## Files

| File | Role |
|---|---|
| `engine-project-core.ts` | Types + project CRUD/zip |
| `engine-project-collab.ts` | Collab SSE/REST |
| `engine-project-files.ts` | Files / revisions / comments |
| `engine-project.ts` | Leaf + re-exports of types + intermediate classes |

## Compatibility

- Types still from `./engine-project.js`  
- `EngineWorkflowClient extends EngineProjectClient` unchanged  
- Method bodies verbatim
