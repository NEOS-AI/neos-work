# v0.3.166 — TradingView MCP for finance / trading work

## Summary

First-class **TradingView MCP** support so NEOS agents can read and analyze live TradingView Desktop charts via the open-source bridge [tradesdontlie/tradingview-mcp](https://github.com/tradesdontlie/tradingview-mcp) (CDP on port 9222).

## What shipped

### MCP client (`@neos-work/mcp-client`)
- **Presets catalog** (`presets.ts`): `tradingview` preset with stdio `node {{installPath}}/src/server.js`, requirements, tool hints (`tv_health_check`, `quote_get`, …).
- **Path hygiene**: `sanitizeMcpInstallPath`, `buildPresetStdioArgs` (control-char / `..` / length caps).
- **CDP probe** (`tradingview-cdp.ts`): `checkTradingViewCdp(port)` hits `http://127.0.0.1:9222/json/version` (+ optional `/json/list`) for Settings “Test CDP”.

### Server
- `GET /api/mcp-servers/presets`
- `POST /api/mcp-servers/from-preset` — validates `src/server.js` exists under install path, creates enabled MCP row
- `GET /api/mcp-servers/tradingview/cdp-health?port=`
- Template **Live Chart Analysis (TradingView)** with `finance_chart_analyst` harness

### Desktop Settings
- TradingView MCP card: path input, **Add TradingView**, **Test CDP :9222**, collapsible setup guide
- Connected badge when an enabled server name contains “tradingview”

### Finance harness
- `finance_chart_analyst` — system prompt for health → quote/state → levels/indicators → JSON bias report
- Sessions load all enabled MCP tools (including `tv_*`) automatically once the preset is added

## Operator setup (short)

1. Node.js LTS + TradingView **Desktop** (paid plan; browser-only unsupported)
2. Clone `tradingview-mcp`, `npm install` (use folder with `package.json` + `src/` directly)
3. Launch TV: `--remote-debugging-port=9222` (quit tray/dock instance first)
4. Settings → MCP → paste install path → Add TradingView
5. New Session: “Run tv_health_check and summarize the open chart”

## Notes
- Chart interaction only — no real trade execution.
- Workflow `AgentNode` still uses local tools only; live chart tools are available in **Sessions** via MCP registration (same path as other MCP servers).
