- promptTemplate max 50_000 chars (create throw / update null)
- Description truncated at 2_000; name max 200

### Task 3: Web search (tool + node)

- `resolveSearchQuery`: reject control chars; cap at 2_000 chars
- `resolveMessageText`: only interpolate safe `{{key}}` (alnum/_/-)

- Inputs must be plain object; reject arrays
- Cap serialized inputs at 256 KiB

### Task 5: Preflight / agent steps (Task 11)
