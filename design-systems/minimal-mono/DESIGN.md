# Minimal Mono

## Overview
High-contrast monochrome palette for wireframes, docs, and low-fidelity prototypes.

## Colors
- Ink: `#111111`
- Paper: `#ffffff`
- Gray 50–500 scale for borders and muted text

## Typography
- Font: ui-monospace, SFMono-Regular, Menlo, monospace
- Prefer single column, 65ch max measure

## Layout
- Generous whitespace; no decorative shadows
- 1px solid borders only
