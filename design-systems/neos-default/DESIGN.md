# NEOS Default Design System

## Overview
Default visual language for NEOS Work Design Projects and generated UI.

## Brand Colors
- Primary: `#6366f1` (indigo)
- Accent: `#22d3ee` (cyan)
- Background: `#0f172a` / Surface `#1e293b`
- Text: `#f8fafc` / Muted `#94a3b8`
- Success `#10b981` · Warning `#f59e0b` · Error `#ef4444`

## Typography
- Font: Inter, system-ui, sans-serif
- Headings: tight tracking, bold
- Body: 14–16px, 1.5 line-height

## Spacing
- Base 4px; scale 4 / 8 / 12 / 16 / 24 / 32 / 48

## Components
- Rounded corners 6–12px
- Subtle borders `rgba(148,163,184,0.2)`
- Prefer accessible focus rings (`outline: 2px solid #6366f1`)
